# Legacy Scripts

This directory hides historical scripts that are preserved for reproducibility
but are not part of the active uSERS-Net/STK-V2 workflow.

Use active entry points instead:

- Training: `scripts/training/train_usersnet.py`
- Production artifact build: `scripts/training/build_usersnet_production.py`
- STK-V2 analysis: `scripts/analysis/stk_v2_full_eval.py`
- STK-V2 figure data export: `scripts/visualization/r/export_stk_v2_data.py`
- STK-V2 R figures: `scripts/visualization/r/stk_v2_figures.R`
