# SERS-AI Agent Instructions

## Analysis presentations

For every analytical, technical, architecture, security, or executive presentation task:

1. Read `docs/presentation/DESIGN.md` completely before creating or editing presentation artifacts.
2. Use HTML/CSS as the default authoring format unless the user explicitly requests another format.
3. Apply the fixed 16:9 canvas, brand tokens, layouts, chart rules, terminology, data-integrity constraints, and QA checklist defined in that document.
4. Treat the repository-root `DESIGN.md` as the clinical web application design system, not the presentation design system.
