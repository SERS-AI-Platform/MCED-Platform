# SERS-AI 임상 웹앱 사용설명서

## 1. 목적

SERS-AI 임상 웹앱은 소변 SERS 스펙트럼 파일을 입력받아 모델 기반 암 선별 참고 지표를 제공하는 소프트웨어이다.

본 시스템의 결과는 최종 진단이 아니다. 결과는 임상 전문의의 판단과 추가 검사 필요성 검토를 보조하기 위한 참고 정보로 사용한다.

## 2. 대상 사용자

| 사용자 | 역할 |
|---|---|
| 검사실 기사 | 환자 정보 입력, 스펙트럼 업로드, QC 결과 확인 |
| 임상의 | 분석 결과 확인, 보고서 검토, 추가 확인 필요성 판단 |
| 관리자 | 사용자 계정, 감사 로그, 시스템 상태 확인 |

## 3. 기본 용어

| 용어 | 의미 |
|---|---|
| SSI 점수 | 모델 확률을 변환한 0-10 범위의 SERS Screening Index |
| SSI 판정 기준값 | SSI 점수를 해석하는 고정 기준값. 현재 기준값은 4.0 |
| 추가 확인 권고 | SSI 점수가 4.0 이상인 상태 |
| 기준 미만 | SSI 점수가 4.0 미만인 상태 |
| 암종 분류 확률 | Stage 2 모델이 산출한 암종별 상대 확률 |

`추가 확인 권고`는 암 진단 또는 강한 양성을 의미하지 않는다. `기준 미만`은 정상 확정 또는 암 없음 확정을 의미하지 않는다.

## 4. 사용 전 준비

1. 시스템이 실행 중인지 확인한다.
2. 사용자 계정으로 로그인한다.
3. 분석할 환자 ID, 나이, 성별, 필요 시 BMI를 준비한다.
4. 환자당 반복 측정 스펙트럼 CSV 파일을 준비한다.
5. CSV는 파수(wavenumber)와 강도(intensity) 2열 구조여야 한다.

## 5. 사용 절차

### 5.1 로그인

1. 사용자 ID와 비밀번호를 입력한다.
2. 로그인 후 환자 정보 입력 화면으로 이동한다.

기존의 운영 모드 선택 단계는 사용하지 않는다. 시스템은 모델에 정의된 표준 판정 기준을 자동 적용한다.

### 5.2 환자 정보 입력

1. 환자번호를 입력한다.
2. 나이를 입력한다.
3. 성별을 선택한다.
4. BMI가 있으면 입력한다. 없으면 생략할 수 있다.
5. `다음`을 선택한다.

성별 정보는 생물학적으로 불가능한 암종 표시를 제한하는 데 사용될 수 있다.

### 5.3 스펙트럼 업로드

1. CSV 파일을 업로드 영역에 드래그하거나 클릭하여 선택한다.
2. 환자당 반복 측정 5개 파일을 권장한다.
3. 최소 1개, 최대 20개 파일을 허용한다.
4. 파일 목록을 확인한다.
5. `분석 시작`을 선택한다.

### 5.4 QC 확인

시스템은 업로드된 스펙트럼에 대해 품질 관리를 수행한다.

| QC 항목 | 의미 |
|---|---|
| 강도 기준 | 신호 강도가 분석 가능한 수준인지 확인 |
| 반복 상관 계수 | 반복 측정 간 일관성을 확인 |

모든 스펙트럼이 QC 기준을 충족하지 않으면 재측정이 필요하다.

### 5.5 결과 확인

결과 화면에는 다음 항목이 표시된다.

| 항목 | 해석 |
|---|---|
| SSI 점수 | 모델의 Stage 1 확률을 0-10 범위로 변환한 선별 지표 |
| SSI 판정 기준값 | SSI 점수 해석 기준. 현재 기준값은 4.0 |
| 추가 확인 권고 / 기준 미만 | 표준 판정 기준에 따른 선별 결과 |
| 최상위 추정 암종 | 추가 확인 권고 시 표시되는 Stage 2 최상위 암종 |
| 암종 분류 확률 | 암종별 상대 확률 |
| 반복 측정 상세 | 각 반복 측정의 SSI 점수와 QC 정보 |

암종 분류 확률은 암종별 진단 확률이 아니라 모델 분류 결과의 상대 점수이다.

### 5.6 보고서 생성

1. 결과 화면에서 `보고서 생성`을 선택한다.
2. 보고서에는 환자 정보, 검사 조건, QC 요약, 분석 결과가 포함된다.
3. 보고서 생성 기록은 감사 추적 로그에 저장된다.

## 6. 결과 해석 원칙

| 화면 표시 | 권장 해석 |
|---|---|
| 추가 확인 권고 | 임상적 맥락과 필요 시 추가 검사를 검토한다. |
| 기준 미만 | 본 검사 기준에서는 추가 확인 권고 수준에 도달하지 않았다. 증상 또는 임상 판단에 따라 추가 평가가 필요할 수 있다. |
| 높은 분류 확률 | Stage 2에서 특정 암종 쪽으로 상대적으로 높게 분류되었다. 최종 진단은 아니다. |

## 7. 금기 또는 제한

- 본 시스템을 단독 진단 근거로 사용하지 않는다.
- SSI 점수를 강한 양성/약한 양성 등급으로 해석하지 않는다.
- QC 실패 스펙트럼을 근거로 결과를 해석하지 않는다.
- 환자 식별 정보와 결과 보고서는 기관 보안 절차에 따라 관리한다.

## 8. 오류 대응

| 상황 | 조치 |
|---|---|
| 로그인 실패 | 사용자 ID/비밀번호를 확인한다. |
| CSV 업로드 실패 | 파일 확장자와 2열 구조를 확인한다. |
| 모든 스펙트럼 QC 실패 | 재측정 후 다시 업로드한다. |
| 보고서 생성 실패 | 관리자에게 오류 메시지와 시간 정보를 전달한다. |

## 9. 감사 추적

시스템은 로그인, 환자 세션 생성, 스펙트럼 업로드, 분석 완료, 보고서 생성 등 주요 행위를 기록한다. 감사 로그는 결과 해석이 아니라 사용 이력 확인 목적이다.
