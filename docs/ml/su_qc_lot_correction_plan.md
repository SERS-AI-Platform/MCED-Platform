# SU 기반 QC 정립 · lot 차이 보정 계획 (2026-10-14)

> 원칙(사용자): SU(모사 소변)는 조성을 아는 유일한 물질이다. SU로 QC를 정립하고, lot 간 차이를 줄이는 정답지로 쓴다.
> 단위: **point**(측정 한 번) ⊂ **strip**(검체 1개당 1개) ⊂ **포장 단위**(SK<lot>-N, 하루 사용, 검체 strip 12~19개 + SU strip 1개) ⊂ **lot**(포장 단위 10개).
> 근거 기록: `docs/ml/experiment.md` PL-4 ~ PL-10, BM-17. 이 문서는 계획이며 수치는 각 Phase 기록에서 가져왔다.

## 1. 지금까지 확인된 것

| 질문 | 결과 | 기록 |
|---|---|---|
| 전처리가 SU 신호를 지우는가 | 평활(SG)은 SU 피크 비를 바꾸고 작은 피크를 지움 → 모델 입력에서 제외. 스파이크 제거는 효과 없음. 바탕선 arPLS·rolling-min + SNV 통과 | PL-4 |
| SU는 lot이 달라도 같은가 | 코사인은 0.97 수준이지만 처음 보는 포장의 SU로 lot을 맞힘(AUC 0.78) → 동일하지 않음 | PL-5 보충 ③ |
| 차이는 어디서 | 피크 위치가 아니라 특정 피크(688·744·935·1000·1448)의 상대 세기·prominence | PL-5 |
| SU의 lot 차이를 지울 수 있는가 | SU lot 배율(raw)로 처음 보는 포장에서 lot 구분 0.78 → 0.50, SU 피크 보존. 포장 간 차이(반복 잡음의 약 2.5배)는 남음 | PL-6 |
| 같은 보정을 검체에 쓰면 | 검체 lot 흔적이 오히려 커짐. 피크마다 SU와 검체가 배율이 다르거나(0.5~0.9) 반대 방향(1000·1371·1665)이고, 검체의 최대 lot 대역(723)은 SU에 없음 | PL-7, 보충 |
| 반영 비율·성분 분해로 쓰면 | 비율(β ≈ 0.15)은 효과 미미, NMF 성분 2~3개는 해 없이 소폭 개선(lot 제외 AUC 0.696 → 0.703) | PL-8, PL-10 |
| SU로 포장 QC 기준을 잡으면 | 잠정 기준(72 포장 분포)으로 3포장 불합격, 그러나 검체 품질과 연관 없음. 5 point로는 피크 지표가 불안정 | PL-9 |

**결론**: SU를 정답지로 쓰는 방향은 유지하되, 지금 SU 데이터(포장당 5 point, 조성 미확정, 성분 스펙트럼 없음)로는 QC 기준값과 검체 보정 모두 해상도가 부족하다. 아래 측정이 필요하다.

## 3. SU QC 판정 체계 (잠정 → 확정 경로)

| 판정 단위 | 지표 | 지금(잠정, PL-9) | 확정 방법 |
|---|---|---|---|
| SU strip (측정 성공) | point 간 코사인, 피크 13개 SNR, 신호 세기 | 반복성 ≥ 0.932, 신호 ±0.58 log2 | M3(36 point)로 분포 재산출 |
| 포장 단위 (그날 측정) | 기준 SU 대비 거리 ÷ 반복 잡음, 강한 피크의 위치·세기 비 | 거리비 ≤ 4.9 | 기준 SU를 M2 성분으로 정의, M3·M6 데이터로 재산출. 약한 피크는 제외 |
| lot (입고) | 기준 lot과 같은 날 비교: lot 구분 AUC, lot 배율 크기 | 현재 lot 구분 0.62~0.94 → 모두 "동일" 기준 불통과 | M6으로 lot 구분 AUC ≤ 0.6 · 배율 ≤ 반복 잡음을 합격 기준으로 검증 |
| 전처리 | SU 피크 보존, 세기 비 변화, 포장 간 차이 감소 | PL-4 기준 | M4·M5로 농도·첨가 보존까지 확인 |

## 4. 검체 lot 보정 경로 (SU 정답지)

1. **성분 단위 보정**: M2 성분 스펙트럼으로 SU를 분해 → lot별 성분 증강 계수 → 검체 피크를 성분 계수로 보정. 평가: PL-7과 같은 지표(잔차 lot η², lot 맞히기 AUC, 암 AUC 무작위 vs lot 제외), 합격 = lot 제외 차이가 시드 편차 이내.
2. **변환 검증·학습**: M7·M8의 같은 소변 재측정으로 "SU로 계산한 보정이 같은 소변을 같게 만드는가" 검증. lot이 충분히 쌓이면 SU→소변 변환 학습(선형 기준 → 필요 시 오토인코더: 입력 = 검체 + 같은 포장 SU, 목표 = 같은 소변 동일 출력 · lot 구분 불가 · SU 피크/첨가 신호 보존 · 진단 정보 유지).
3. **보강 SU(M9)**: 1·2에서 SU와 소변의 반응 차이가 크면, 보강 SU로 상관을 높인 뒤 1을 반복.

## 5. 측정 원칙 (지금부터 적용)

- 포장 단위마다 SU strip 포함(현행 유지), 가능하면 시작·끝 2회(M3).
- 매 포장·매 lot에 모든 군을 무작위로 섞어 배치 — 남는 strip·포장 차이가 질환 신호와 겹치지 않게.
- 새 lot은 기준 lot과 같은 날 병행 측정(M6).
- 측정 기록에 포장 번호, SU strip 번호, 측정 순서(시각)를 남긴다.
