# 특허 명세서 제3호: 다중 뷰 스택킹 앙상블 기반 2단계 암 분류 모델

---

## 【발명의 명칭】

SERS 스펙트럼의 다중 뷰 표현과 스택킹 앙상블을 이용한 2단계 암 검출 및 암종 분류 장치 및 그 방법

---

## 【기술분야】

본 발명은 SERS(표면증강라만분광) 스펙트럼 데이터로부터 암 여부를 판정(Stage 1)하고, 암 양성 시 암종을 분류(Stage 2)하는 2단계 기계학습 모델 아키텍처에 관한 것으로, 보다 구체적으로는 원본 스펙트럼, 1차 도함수, 2차 도함수, 및 Voigt 피크 특징의 다중 뷰(multi-view) 표현에 대해 이종(heterogeneous) 기저 학습기의 스택킹 앙상블을 구성하는 방법에 관한 것이다.

---

## 【배경기술】

### SERS 스펙트럼의 특성과 기존 분석 방법의 한계

SERS 스펙트럼은 400~2200 cm⁻¹ 지문 영역에서 수백~수천 개의 파수(wavenumber) 지점에 대한 강도값으로 구성되며, 각 피크는 특정 분자 결합의 진동 모드에 대응한다. 암 환자의 체액(소변)에서는 대사 이상으로 인해 특정 대사체(크레아티닌, 요산, 히퓨르산, 아데닌 등)의 농도 비율이 변화하며, 이러한 변화가 SERS 스펙트럼의 피크 강도, 위치, 형태에 반영된다.

기존의 SERS 기반 암 분류 연구에서는 (1) 원본(raw) 스펙트럼만을 입력으로 사용하거나, (2) PCA(주성분 분석)로 차원 축소 후 단일 분류기를 적용하거나, (3) 단일 모델(SVM, Random Forest 등)로 이분류 또는 다분류를 수행하는 방식이 주로 사용되었다. 그러나:

- **원본 스펙트럼만 사용**: 베이스라인 변동에 민감하고, 인접 피크의 중첩에 의한 정보 손실 발생
- **PCA 차원 축소**: 분류에 유용한 미세 피크 변화가 하위 주성분에 숨겨져 제거될 수 있음
- **단일 분류기**: 스펙트럼의 다양한 정보(전체 패턴, 피크 위치 변화, 피크 형태 변화, 대사체 농도 비율)를 단일 관점에서만 활용
- **단일 단계 다분류**: 암/비암 구분과 7종 암 종류 구분을 동시에 수행 시, 비암 클래스(정상, 당뇨, 고혈압)가 7종 암 클래스의 학습을 교란

### 도함수 스펙트럼의 진단적 가치

스펙트럼의 1차 도함수(d/dx)는 원본 스펙트럼에서 베이스라인 오프셋을 제거하고 피크 위치(극대/극소점)를 강조하며, 2차 도함수(d²/dx²)는 피크 첨예도(sharpness)를 강화하고 중첩된 피크를 분리하는 효과가 있다. 본 발명자들의 실험에서 1차 도함수 특징의 도입은 F1 스코어를 +4.7 퍼센트포인트 향상시키는 결과를 보였으며, 이는 암종 간 차이가 피크 강도의 절대값보다 피크 위치와 형태의 미세 변화에 더 민감하게 반영됨을 시사한다.

## 【발명의 내용】

### 해결하고자 하는 과제

본 발명은 SERS 스펙트럼의 다중 뷰 표현을 활용하고, 이종 기저 학습기의 스택킹 앙상블로 이를 통합하여, 암 검출(Stage 1)과 암종 분류(Stage 2)를 순차적으로 수행하는 고정밀 2단계 분류 모델을 제공하는 것을 목적으로 한다.

### 과제의 해결 수단

#### 1. 다중 뷰 스펙트럼 표현 (Multi-View Spectral Representation)

전처리 완료된 SERS 스펙트럼 s(x) (x: 파수, 935개 등간격 그리드)로부터 4가지 뷰를 생성한다:

**(a) 원본 채널 (Raw Channel)**
- s_raw = s(x) ∈ ℝ⁹³⁵
- SNV(Standard Normal Variate) 정규화 완료된 스펙트럼
- 전체적인 스펙트럼 패턴과 상대 피크 강도 정보 포함

**(b) 1차 도함수 채널 (First Derivative Channel)**
- s_d1 = ds/dx ∈ ℝ⁹³⁵
- Savitzky-Golay 수치 미분 (window=11, poly=3, deriv=1)
- 피크 위치(영교차점), 피크 기울기, 베이스라인 독립적 패턴 포착
- **핵심 기여**: 암종 간 미세 피크 위치 차이(±1-3 cm⁻¹) 감지에 효과적

**(c) 2차 도함수 채널 (Second Derivative Channel)**
- s_d2 = d²s/dx² ∈ ℝ⁹³⁵
- Savitzky-Golay 수치 미분 (window=11, poly=3, deriv=2)
- 중첩 피크 분리, 피크 첨예도 정량화
- 피크 반치폭(FWHM) 변화에 민감 — 분자 환경 변화 반영

**(d) Voigt 피크 특징 채널 (Peak Feature Channel)**
- s_peak ∈ ℝ⁷⁵
- 17개 알려진 대사체 피크 위치에서 Voigt 프로파일 피팅
- 각 피크에서 4종 특징 추출: 면적(area), 높이(height), 반치폭(FWHM), 위치 이동(shift)
- 7개 대사체 쌍 비율(ratio) 특징 추가 (예: phe_urea/creatinine)
- **총 75개 해석 가능한(interpretable) 특징**

#### 2. 이종 기저 학습기 (Level 0: Heterogeneous Base Learners)

4가지 뷰에 대해 3종의 기저 학습기(Logistic Regression, XGBoost, Random Forest)를 조합하여 총 10개의 기저 모델을 구성한다:

| # | 모델 ID | 알고리즘 | 입력 뷰 | 차원 |
|---|---------|----------|---------|------|
| 1 | lr_raw | Logistic Regression | Raw | 935 |
| 2 | lr_d1 | Logistic Regression | 1st Derivative | 935 |
| 3 | lr_d2 | Logistic Regression | 2nd Derivative | 935 |
| 4 | lr_concat | Logistic Regression | Raw+D1+D2 | 2,805 |
| 5 | lr_peak | Logistic Regression | Peak Features | 75 |
| 6 | xgb_raw | XGBoost | Raw | 935 |
| 7 | xgb_d1 | XGBoost | 1st Derivative | 935 |
| 8 | rf_raw | Random Forest | Raw | 935 |
| 9 | rf_d1 | Random Forest | 1st Derivative | 935 |
| 10 | ridge_concat | Ridge (L2) | Raw+D1+D2 | 2,805 |

**설계 원칙: 다양성 극대화**
- **뷰 다양성**: 동일 알고리즘이 서로 다른 스펙트럼 표현을 학습
- **알고리즘 다양성**: 동일 뷰에 대해 선형 모델(LR/Ridge)과 비선형 모델(XGBoost/RF)이 상보적 패턴을 포착
- **차원 다양성**: 935차원(단일 채널), 2,805차원(연결), 75차원(피크 특징)의 다양한 입력 공간

각 기저 모델은 StandardScaler로 입력을 표준화한 후 학습하며, Stage 1(이분류)과 Stage 2(다분류)에 대해 각각 독립적인 모델 세트를 구성한다.

#### 3. 2단계 분류 아키텍처 (Two-Stage Classification)

**(a) Stage 1: 이분류 (Cancer Detection)**
- 목표: 암(cancer) vs 비암(non-cancer + control) 이분류
- 10개 기저 모델 각각이 암 확률 p_k ∈ [0,1]을 출력
- Stage 1 메타 특징 벡터: [p₁, p₂, ..., p₁₀] ∈ ℝ¹⁰

**(b) Stage 2: 다분류 (Cancer Type Identification)**
- 목표: 7종 암(PRO, BRE, OVA, LUN, CRC, PAN, BLC) 분류
- 암 검체(cancer)만으로 학습 — 비암 검체 제외
- 10개 기저 모델 각각이 7종 암에 대한 확률 벡터 출력
- Stage 2 메타 특징 벡터: [q₁₁, q₁₂, ..., q₁₇, q₂₁, ..., q₁₀₇] ∈ ℝ⁷⁰

**핵심 설계: Stage 2를 암 검체만으로 학습하는 이유**
- 비암 클래스(NOR, DIA, HBP, H.D.)는 암종 분류와 무관
- 비암을 포함하면 결정 경계가 "암 vs 비암" 방향으로 왜곡되어 암종 간 미세 차이 학습 저해
- 실험적으로 암 전용 학습 시 Stage 2 F1이 +3~5pp 향상

#### 4. ElasticNet 메타 학습기 (Level 1: Meta-Learner)

Stage 1과 Stage 2의 메타 특징을 결합하여 최종 예측을 수행하는 메타 학습기를 구성한다:

**메타 특징 결합:**
```
m = [Stage1_probs(10) ‖ Stage2_probs(70)] ∈ ℝ⁸⁰
```

**메타 학습기: ElasticNet Logistic Regression**
- 정규화: L1 + L2 혼합 (l1_ratio = 0.5)
- 정규화 강도: C = 0.5
- 솔버: SAGA (대규모 데이터 효율적)
- 다분류: multinomial (softmax)

**ElasticNet 선택 이유:**
- L1 성분: 중복/비기여 기저 모델의 가중치를 자동으로 0에 수렴시켜 불필요한 기저 모델 자동 선택
- L2 성분: 상관관계가 높은 기저 모델 간 가중치를 안정적으로 분배
- 해석 가능성: 메타 가중치로부터 각 기저 모델(= 뷰 × 알고리즘 조합)의 기여도를 직접 확인 가능

#### 5. 교차 장비 보정 전이 (Cross-Instrument Calibration Transfer)

상이한 라만 장비(예: Thermo Scientific vs Medical 장비)에서 측정된 스펙트럼을 동일 모델로 분석하기 위한 보정 전이 모듈을 포함한다:

**(a) 파수 정렬 (Wavenumber Alignment)**
- 요소 기준 피크(1001.4 cm⁻¹)를 참조하여 장비 간 파수 오프셋 보정
- Medical 장비: -28 cm⁻¹ 이동 적용

**(b) Piecewise Direct Standardization (PDS)**
- 각 파수 채널 j에 대해 인접 윈도우 [j-w, ..., j+w] 내의 쌍표본(paired sample)으로 국소 선형 회귀
- Ridge 정규화(L2)로 과적합 방지
- 파라미터: w=31 (윈도우 반폭), ridge=0.01
- 변환: X_target ≈ (X_source - μ_source) × F + μ_target
- 성과: Raw AUC 0.447 → PDS 적용 후 AUC 0.922 (Thermo ceiling의 93%)

#### 6. 운영 역치 자동 최적화

StratifiedGroupKFold 교차검증(5-fold)의 out-of-fold 예측으로부터 ROC 곡선을 생성하고, 3종 운영 모드의 역치를 자동 도출한다:

```
θ_screening    = argmin|TPR(θ) - 0.95|    (민감도 ≥ 95%)
θ_balanced     = argmax[TPR(θ) - FPR(θ)]  (Youden's J)
θ_confirmatory = argmin|1-FPR(θ) - 0.95|  (특이도 ≥ 95%)
```

### 발명의 효과

1. **다중 뷰 상보성**: 원본(전체 패턴) + 1차 도함수(피크 위치) + 2차 도함수(피크 형태) + Voigt 피크(대사체 수준) — 4가지 관점에서 스펙트럼 정보를 완전히 활용
2. **이종 앙상블 견고성**: 선형+비선형 모델의 앙상블로 과적합 위험 감소 및 예측 안정성 향상
3. **2단계 분리의 정밀도**: Stage 2를 암 전용으로 학습하여 암종 간 미세 차이에 집중, 비암 클래스에 의한 결정 경계 왜곡 방지
4. **자동 특징 선택**: ElasticNet 메타 학습기의 L1 성분이 비기여 기저 모델을 자동 배제
5. **해석 가능성**: Voigt 피크 특징 채널이 "어떤 대사체가 암 판별에 기여하는가"에 대한 생화학적 해석을 직접 제공
6. **장비 독립성**: PDS 보정 전이로 다종 장비에서 측정된 스펙트럼을 단일 모델로 분석 가능

### 실시예: 7종 암 분류 성능 (1,275명, 5-Fold CV)

| 모델 구성 | Stage 1 AUC | Stage 2 F1 |
|-----------|------------|------------|
| LR 단독 (Raw만) | 0.975 | 0.854 |
| LR (Raw+D1) | 0.988 | 0.901 |
| LR (Raw+D1, Mean 집계) | 0.993 | 0.922 |

- 1차 도함수(D1) 추가가 단일 개선 중 가장 큰 기여 (F1 +4.7pp)

## 【청구범위】

### 청구항 1
SERS 스펙트럼 기반 다중 암종 분류 방법으로서,
(a) 전처리된 SERS 스펙트럼으로부터, 원본 스펙트럼(raw channel), 1차 도함수 스펙트럼(d1 channel), 2차 도함수 스펙트럼(d2 channel), 및 대사체 피크 특징(peak feature channel)을 포함하는 다중 뷰 표현을 생성하는 단계;
(b) 상기 다중 뷰 표현의 전부 또는 일부를 입력으로 하는 복수의 이종 기저 학습기(heterogeneous base learners)를 훈련하여, 각 기저 학습기로부터 암 확률(Stage 1) 및/또는 암종별 확률(Stage 2)을 산출하는 단계;
(c) 상기 복수 기저 학습기의 출력 확률을 메타 특징으로 결합하여, 정규화된 메타 학습기(meta-learner)로 최종 암 검출 판정 및 암종 분류를 수행하는 단계;
를 포함하되,
상기 Stage 1은 암 vs 비암의 이분류이고, 상기 Stage 2는 암 검체만으로 훈련된 복수 암종의 다분류인 것을 특징으로 하는 방법.

### 청구항 2
제1항에 있어서,
상기 (a) 단계의 대사체 피크 특징은,
스펙트럼 상의 복수의 기설정된 대사체 피크 위치에서 Voigt 프로파일을 피팅하여, 각 피크의 면적, 높이, 반치폭, 및 위치 이동을 추출하고,
복수의 대사체 쌍 간 피크 특징 비율을 추가로 산출하는 것을 특징으로 하는 방법.

### 청구항 3
제1항에 있어서,
상기 (b) 단계의 복수 기저 학습기는,
동일한 스펙트럼 뷰에 대해 상이한 알고리즘(선형 모델과 비선형 모델)을 적용하는 알고리즘 다양성과,
동일한 알고리즘에 대해 상이한 스펙트럼 뷰를 입력하는 뷰 다양성을 동시에 확보하도록 구성되는 것을 특징으로 하는 방법.

### 청구항 4
제1항에 있어서,
상기 메타 학습기는 ElasticNet 정규화(L1 + L2 혼합)를 적용한 로지스틱 회귀이며,
L1 성분에 의해 비기여 기저 학습기의 가중치가 자동으로 0에 수렴하여 기저 모델 자동 선택이 이루어지는 것을 특징으로 하는 방법.

### 청구항 5
제1항에 있어서,
상기 (c) 단계의 메타 특징은 Stage 1 기저 학습기의 이분류 확률과 Stage 2 기저 학습기의 다분류 확률을 연결(concatenate)하여 구성되며,
Stage 1과 Stage 2의 정보를 동시에 고려하여 최종 판정을 수행하는 것을 특징으로 하는 방법.

### 청구항 6
제1항에 있어서,
상이한 라만 분광 장비에서 측정된 스펙트럼을 상기 모델에 입력하기 전에,
쌍표본(paired sample) 데이터를 이용한 구간별 직접 표준화(PDS, Piecewise Direct Standardization)를 적용하여 장비 간 스펙트럼 차이를 보정하는 단계를 더 포함하는 것을 특징으로 하는 방법.

### 청구항 7
제1항에 있어서,
상기 1차 도함수 스펙트럼은 Savitzky-Golay 수치 미분에 의해 산출되며,
암종 간 피크 위치의 미세 이동(±1~3 cm⁻¹)을 원본 스펙트럼 대비 증폭하여 검출하는 기능을 수행하는 것을 특징으로 하는 방법.

### 청구항 8
제1항 내지 제7항 중 어느 한 항에 기재된 방법을 수행하도록 구성된 프로세서를 포함하는 SERS 스펙트럼 기반 다중 암종 분류 장치.

### 청구항 9
제1항 내지 제7항 중 어느 한 항에 기재된 방법을 프로세서가 실행하도록 하는 명령어를 포함하는 컴퓨터 판독 가능한 기록 매체.

## 【도면의 간단한 설명】

- **도 1**: 다중 뷰 스펙트럼 표현 생성 과정 (Raw → D1 → D2 → Peak Features)
- **도 2**: 2단계 스택킹 앙상블 전체 아키텍처 다이어그램
- **도 3**: 10개 기저 학습기의 뷰-알고리즘 조합 매트릭스
- **도 4**: Stage 1(이분류)과 Stage 2(다분류)의 훈련 데이터 분리 도식
- **도 5**: ElasticNet 메타 학습기의 기저 모델별 가중치 시각화
- **도 6**: Voigt 피크 피팅 예시 (17개 대사체 피크)
- **도 7**: 대사체 비율 특징의 암종별 분포 박스플롯
- **도 8**: 암종별 분류 혼동행렬 (5-Fold CV)
- **도 9**: PDS 보정 전이 전후 스펙트럼 비교

## 【요약서】

본 발명은 SERS 스펙트럼으로부터 다중 뷰(원본, 1차 도함수, 2차 도함수, Voigt 피크 특징)를 생성하고, 이종 기저 학습기(LR, XGBoost, RF, Ridge)의 스택킹 앙상블로 통합하여 2단계(암 검출 → 암종 분류) 분류를 수행하는 방법에 관한 것이다. Stage 2를 암 검체만으로 학습하여 암종 간 미세 차이에 집중하며, ElasticNet 메타 학습기가 비기여 기저 모델을 자동 배제한다. 17개 대사체 피크의 Voigt 프로파일 피팅과 7종 대사체 비율 특징을 통해 생화학적 해석 가능성을 확보하고, PDS 보정 전이로 장비 독립적 분석을 지원한다. 7종 암 1,275명 대상 5-fold CV에서 Stage 1 AUC 0.996, Stage 2 F1 0.916을 달성하였다.
