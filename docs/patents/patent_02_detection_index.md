# 특허 명세서 제2호: SERS 스펙트럼 기반 암 검출 지수 산출 장치 및 방법

---

## 【발명의 명칭】

표면증강라만분광 스펙트럼의 다중 반복측정 확률을 통합한 암 검출 지수 산출 장치 및 그 방법

---

## 【기술분야】

본 발명은 표면증강라만분광(SERS) 기반 체외진단에서, 동일 검체로부터 획득된 복수의 반복측정 스펙트럼의 기계학습 예측 확률을 통합하여 임상적으로 해석 가능한 정량적 암 검출 지수를 산출하는 장치 및 방법에 관한 것이다.

---

## 【배경기술】

SERS 기반 진단에서 동일 검체에 대해 복수 회(통상 5회)의 반복측정을 수행하는 것은 측정 재현성을 확보하기 위한 표준 프로토콜이다. 각 반복측정은 나노기판 위의 서로 다른 핫스팟(hot-spot)에서 획득되므로, 동일 검체라 하더라도 스펙트럼 강도에 2~10배의 변이가 발생할 수 있다. 이러한 변이는 SERS 고유의 물리적 특성에 기인하며, 진단적 가치가 있는 분자 지문 패턴과는 독립적이다.

기존 기술에서는 (1) 복수 반복측정의 평균 스펙트럼을 산출한 후 단일 예측을 수행하거나(평균 후 예측), (2) 대표 스펙트럼(medoid)만 선택하여 예측을 수행하는 방식이 사용되었다. 그러나 평균 후 예측 방식은 품질이 낮은 개별 스펙트럼의 영향을 사전에 배제하기 어렵고, medoid 선택 방식은 4~5회 반복측정의 정보를 1회분으로 축소하여 통계적 검정력을 손실한다.

또한, 기계학습 모델이 출력하는 0~1 범위의 확률값은 비임상 전문가(환자, 일반 의료진)에게 직관적이지 않으며, 기존의 암 선별검사 지표(예: OVA1의 0~10 스케일, Oncotype DX의 0~100 스케일)와 같은 임상 친화적 지수 체계가 SERS 분야에는 부재하다.

---

## 【발명의 내용】

### 해결하고자 하는 과제

본 발명은 (1) 품질관리를 통과한 복수 반복측정의 개별 예측 확률을 통합하여 검체 단위의 단일 확률을 산출하고, (2) 이를 임상적으로 해석 가능한 0-10 스케일 지수로 변환하며, (3) 다수결 투표 기반의 이중 확인 메커니즘을 제공하는 암 검출 지수 산출 방법을 제공하는 것을 목적으로 한다.

### 과제의 해결 수단

본 발명에 따른 암 검출 지수 산출 방법은 다음 단계를 포함한다:

#### 단계 1: 개별 반복측정 예측 (Predict-then-Aggregate)

동일 검체의 N회 반복측정 스펙트럼 {s₁, s₂, ..., sₙ} 중 QC를 통과한 K개(K ≤ N)에 대해 각각 독립적으로 기계학습 모델을 적용하여 개별 암 확률 {p₁, p₂, ..., pₖ}를 산출한다.

**핵심 설계 원칙: "Predict-then-Aggregate"**
- 종래의 "Aggregate-then-Predict" (평균 스펙트럼 → 단일 예측) 방식과 구별됨
- 각 반복측정을 독립 예측하므로, QC 실패 스펙트럼을 예측 전에 배제 가능
- 개별 예측의 분산(variance)이 측정 불확실성의 직접적 추정치가 됨

#### 단계 2: 검체 단위 확률 통합

QC 통과 반복측정의 개별 확률을 산술 평균하여 검체 단위 확률 P를 산출한다:

```
P = (1/K) × Σᵢ₌₁ᴷ pᵢ
```

여기서 K는 QC 통과 반복측정 수, pᵢ는 i번째 반복측정의 암 확률이다.

#### 단계 3: SERS 선별지수(SSI) 산출

검체 단위 확률 P를 기설정된 운영 역치(θ)를 기준점으로 하는 구간별 선형 변환(Piecewise Linear Transform)을 적용하여 0-10 스케일의 SSI를 산출한다:

```
        ⎧ 4.0 × (P / θ)                    , P ≤ θ
SSI =   ⎨
        ⎩ 4.0 + 6.0 × (P - θ) / (1 - θ)   , P > θ
```

여기서:
- θ: 운영 모드에 따른 의사결정 역치
  - 선별 모드(Screening): 민감도 ≥ 95%를 달성하는 역치 (통상 0.30~0.40)
  - 균형 모드(Balanced): Youden's J 통계량을 최대화하는 역치 (통상 0.45~0.55)
  - 확인 모드(Confirmatory): 특이도 ≥ 95%를 달성하는 역치 (통상 0.65~0.75)
- SSI = 4.0: 항상 운영 역치(θ)에 대응하는 고정 분할점(cutoff)

**수학적 특성:**
- 단조증가(monotonically increasing): SSI는 P에 대해 순증가
- 순서보존(rank-preserving): SSI에 의한 순위와 원 확률 P에 의한 순위가 동일
- 가역(invertible): SSI로부터 원 확률 P를 복원 가능
  ```
  P = θ × (SSI / 4.0)                    , SSI ≤ 4.0
  P = θ + (1-θ) × (SSI - 4.0) / 6.0     , SSI > 4.0
  ```
- AUC/민감도/특이도 불변: 분류 성능 지표가 변환에 의해 변하지 않음

#### 단계 4: 위험도 수준 분류

SSI를 5단계 위험도 수준으로 분류한다:

| 수준 | SSI 범위 | 색상 코드 | 임상적 의미 |
|------|----------|-----------|-------------|
| 낮음(Low) | 0.0 ~ 2.0 | 녹색(#059669) | 정상 범위 |
| 낮음-중간(Low-Moderate) | 2.0 ~ 4.0 | 연두(#84CC16) | 관찰 권고 |
| 중간(Moderate) | 4.0 ~ 6.0 | 황색(#D97706) | 추가 검사 권고 |
| 높음(High) | 6.0 ~ 8.0 | 주황(#EA580C) | 정밀 검사 필요 |
| 매우 높음(Very High) | 8.0 ~ 10.0 | 적색(#DC2626) | 즉시 정밀 검사 |

#### 단계 5: 다수결 투표(Majority Vote) 이중 확인

개별 반복측정의 양성 판정 비율을 산출하여 SSI 기반 판정의 이중 확인 수단으로 활용한다:

```
V = (1/K) × Σᵢ₌₁ᴷ I(pᵢ > θ)
```

여기서 I(·)는 지시함수이다. V > 0.5 (과반수 양성) 시 양성으로 판정한다.

**SSI와 다수결의 조합 해석:**
- SSI > 4.0 AND V > 0.5: 강한 양성 → 높은 신뢰도
- SSI > 4.0 AND V ≤ 0.5: 일부 스펙트럼만 양성 → 재검 권고
- SSI ≤ 4.0 AND V > 0.5: 확률은 낮으나 빈도는 높음 → 재검 권고
- SSI ≤ 4.0 AND V ≤ 0.5: 강한 음성 → 높은 신뢰도

#### 단계 6: 암종 분류 지수(Cancer Type Index, CTI)

Stage 2 다분류 모델의 softmax 확률을 10을 곱하여 0-10 스케일로 변환한다:

```
CTIⱼ = round(softmax_probⱼ × 10.0, 1)
```

여기서 j는 암종 인덱스이다. 최대 CTI를 갖는 암종이 예측 암종이 되며, 해당 CTI 값이 신뢰도를 나타낸다:
- 높은 신뢰도: CTI ≥ 7.0 (softmax ≥ 70%)
- 중간 신뢰도: 4.0 ≤ CTI < 7.0 (40% ≤ softmax < 70%)
- 낮은 신뢰도: CTI < 4.0 (softmax < 40%)

### 발명의 효과

1. **Predict-then-Aggregate 패러다임**: 종래의 Aggregate-then-Predict 대비, QC 실패 스펙트럼의 사전 배제가 가능하고 측정 불확실성을 정량화할 수 있음
2. **임상 친화적 지수 체계**: 0-10 스케일은 기존 IVD 지수(OVA1 등)와 유사한 형태로 임상 현장에서의 수용성이 높음
3. **역치 독립적 비교**: SSI 4.0이 항상 양성/음성 분할점에 대응하므로, 운영 모드가 변경되어도 "SSI 4.0 이상 = 양성"이라는 일관된 해석이 가능
4. **이중 확인 메커니즘**: SSI(확률 크기 기반)와 다수결 투표(빈도 기반)의 조합으로 판정 신뢰도를 객관적으로 평가
5. **정보 보존**: 순서보존 및 가역 변환으로 원 확률 정보가 손실되지 않으며, AUC 등 분류 성능 지표가 변하지 않음

## 【발명을 실시하기 위한 구체적인 내용】

### 실시예 1: SSI 산출 과정 (선별 모드, θ = 0.35)

1. 5회 반복측정 중 4회 QC 통과
2. 개별 암 확률: p₁=0.82, p₂=0.79, p₃=0.85, p₄=0.81
3. 검체 단위 확률: P = (0.82+0.79+0.85+0.81)/4 = 0.8175
4. SSI 산출: P > θ이므로 SSI = 4.0 + 6.0 × (0.8175 - 0.35) / (1 - 0.35) = 4.0 + 6.0 × 0.719 = **8.3**
5. 위험도: "매우 높음" (8.0~10.0 구간)
6. 다수결: 4/4 양성 → V = 1.0 > 0.5 → 양성 확인
7. 복합 판정: SSI > 4.0 AND V > 0.5 → **강한 양성, 높은 신뢰도**

### 실시예 2: 경계 사례 (균형 모드, θ = 0.50)

1. 5회 반복측정 전체 QC 통과
2. 개별 암 확률: p₁=0.52, p₂=0.48, p₃=0.55, p₄=0.43, p₅=0.51
3. 검체 단위 확률: P = 0.498
4. SSI = 4.0 × (0.498 / 0.50) = **3.98** (음성 측 경계)
5. 다수결: 3/5 양성 → V = 0.6 > 0.5
6. 복합 판정: SSI ≤ 4.0 BUT V > 0.5 → **불일치, 재검 권고**

### 실시예 3: 운영 모드 간 SSI 비교

동일 검체(P = 0.60)에 대한 모드별 SSI:
- 선별 모드(θ=0.35): SSI = 4.0 + 6.0 × (0.60-0.35)/(1-0.35) = **6.3** (높음)
- 균형 모드(θ=0.50): SSI = 4.0 + 6.0 × (0.60-0.50)/(1-0.50) = **5.2** (중간)
- 확인 모드(θ=0.70): SSI = 4.0 × (0.60/0.70) = **3.4** (낮음-중간)

→ 동일 확률이더라도 운영 모드에 따라 SSI와 위험도 수준이 달라지며, 이는 각 모드의 임상적 목적(민감도 우선 vs 특이도 우선)을 반영한다.

## 【청구범위】

### 청구항 1
SERS 스펙트럼 기반 암 검출 지수 산출 방법으로서,
(a) 동일 검체에서 획득된 복수의 반복측정 SERS 스펙트럼 중 품질관리를 통과한 K개의 스펙트럼 각각에 대해 독립적으로 기계학습 모델을 적용하여 개별 암 확률 {p₁, p₂, ..., pₖ}를 산출하는 단계;
(b) 상기 개별 암 확률의 산술 평균으로 검체 단위 확률 P를 산출하는 단계;
(c) 기설정된 운영 역치(θ)를 분할점으로 하는 구간별 선형 변환을 적용하여, 상기 검체 단위 확률 P를 0 내지 10의 스케일을 갖는 SERS 선별지수(SSI)로 변환하되, SSI 값 4.0이 항상 상기 운영 역치에 대응하도록 변환하는 단계;
(d) 상기 SSI를 복수의 위험도 수준으로 분류하는 단계;
를 포함하는 것을 특징으로 하는 암 검출 지수 산출 방법.

### 청구항 2
제1항에 있어서,
상기 (c) 단계의 구간별 선형 변환은,
P ≤ θ인 경우 SSI = 4.0 × (P / θ),
P > θ인 경우 SSI = 4.0 + 6.0 × (P - θ) / (1 - θ)
로 산출되는 것을 특징으로 하며,
상기 변환은 단조증가, 순서보존, 및 가역의 수학적 특성을 갖는 것을 특징으로 하는 방법.

### 청구항 3
제1항에 있어서,
상기 개별 암 확률 각각을 상기 운영 역치와 비교하여 개별 양성/음성을 판정하고, 양성 판정 비율(다수결 투표값 V)을 산출하는 단계를 더 포함하며,
상기 SSI와 상기 다수결 투표값 V의 조합에 기초하여 판정 신뢰도를 4단계(강한 양성, 재검 권고 양성, 재검 권고 음성, 강한 음성)로 분류하는 것을 특징으로 하는 방법.

### 청구항 4
제1항에 있어서,
상기 운영 역치(θ)는 교차검증(cross-validation)에서 산출된 ROC 곡선으로부터,
- 민감도 ≥ 95%를 달성하는 선별 모드 역치,
- Youden's J 통계량을 최대화하는 균형 모드 역치, 및
- 특이도 ≥ 95%를 달성하는 확인 모드 역치
중 선택된 하나인 것을 특징으로 하는 방법.

### 청구항 5
제1항에 있어서,
상기 (a) 단계에서 다분류 모델을 추가로 적용하여 복수 암종에 대한 softmax 확률 벡터를 산출하고,
상기 softmax 확률에 10을 곱하여 0-10 스케일의 암종 분류 지수(CTI)를 산출하는 단계를 더 포함하는 것을 특징으로 하는 방법.

### 청구항 6
제1항에 있어서,
상기 (a) 단계는 복수 스펙트럼의 평균을 산출한 후 단일 예측을 수행하는 방식(Aggregate-then-Predict)이 아닌, 개별 스펙트럼 각각에 대해 독립적으로 예측을 수행한 후 확률을 통합하는 방식(Predict-then-Aggregate)으로 수행되며,
이를 통해 품질관리 실패 스펙트럼의 예측 전 배제 및 개별 예측 분산을 통한 측정 불확실성 추정이 가능한 것을 특징으로 하는 방법.

### 청구항 7
제1항 내지 제6항 중 어느 한 항에 기재된 방법을 수행하도록 구성된 프로세서를 포함하는 SERS 스펙트럼 기반 암 검출 지수 산출 장치.

### 청구항 8
제1항 내지 제6항 중 어느 한 항에 기재된 방법을 프로세서가 실행하도록 하는 명령어를 포함하는 컴퓨터 판독 가능한 기록 매체.

## 【요약서】

본 발명은 SERS 기반 다중 암 선별검사에서 동일 검체의 복수 반복측정으로부터 임상적으로 해석 가능한 암 검출 지수를 산출하는 방법에 관한 것이다. 개별 반복측정에 독립적으로 기계학습 모델을 적용(Predict-then-Aggregate)하여 품질관리 실패 데이터의 사전 배제를 가능하게 하고, 운영 역치를 분할점으로 하는 구간별 선형 변환을 통해 0-10 스케일의 SERS 선별지수(SSI)를 산출한다. SSI 4.0이 항상 양성/음성 분할점에 대응하도록 설계되어 운영 모드에 무관한 일관된 해석이 가능하며, 다수결 투표와의 조합으로 이중 확인 메커니즘을 제공한다. 5단계 위험도 수준 분류를 통해 임상 의사결정을 직관적으로 지원한다.
