# 사용 요구사항-평가 추적표

## 1. 주요 사용 요구사항

| ID | 사용 요구사항 | 관련 위험 | 평가 방법 | 성공 기준 |
|---|---|---|---|---|
| UR-01 | 사용자는 로그인 후 환자 정보 입력 화면으로 진입할 수 있어야 한다. | 접근 실패, 잘못된 사용자 사용 | 시나리오 A | 도움 없이 로그인 및 환자 입력 화면 도달 |
| UR-02 | 사용자는 환자 ID, 나이, 성별, BMI를 입력할 수 있어야 한다. | 잘못된 환자 정보로 결과 기록 | 시나리오 A | 필수 항목 누락 없이 입력 |
| UR-03 | 사용자는 CSV 스펙트럼 파일을 업로드할 수 있어야 한다. | 잘못된 파일 입력 | 시나리오 A | 올바른 파일 선택 및 분석 시작 |
| UR-04 | 사용자는 QC 통과/실패 상태와 치명적 QC 실패의 검사 무효 처리를 이해할 수 있어야 한다. | 품질 부적합 데이터를 신뢰 | 시나리오 B | 강도 부족·스파이크 잡음·포화 시 결과 미표시와 재측정 필요성 설명 |
| UR-05 | 사용자는 평균 SSI의 세 구간이 서로 다른 선별 조치 문구를 결정함을 이해해야 한다. | 점수를 진단 확률로 오해 | 시나리오 C | 1.0과 4.0 포함 경계를 정확히 설명 |
| UR-06 | 사용자는 `추가 확인 권고`가 암 진단이 아님을 이해해야 한다. | 암 진단으로 오해 | 시나리오 C | 중대한 오해 0건 |
| UR-07 | 사용자는 `기준 미만`이 정상 확정이 아님을 이해해야 한다. | 암 없음으로 오해 | 시나리오 C | 중대한 오해 0건 |
| UR-08 | 사용자는 암종 분류 점수가 최종 암종 확정 또는 진단 확률이 아님을 이해해야 한다. | 암종 확정으로 오해 | 시나리오 C | 중대한 오해 0건 |
| UR-09 | 사용자는 환자마다 운영 모드를 선택하지 않아야 한다. | 데이터 단위 기준 변경 오해 | 시나리오 A/C | 표준 판정 기준을 고정 기준으로 설명 |
| UR-10 | 사용자는 보고서를 생성하고 화면 결과와 같은 용어를 확인할 수 있어야 한다. | 보고서와 화면 불일치 | 시나리오 D | 보고서 용어 일관성 확인 |
| UR-11 | 시스템은 분석 및 보고서 생성 이력을 감사 로그에 남겨야 한다. | 추적성 부족 | 시나리오 D | 감사 로그 기록 확인 |
| UR-12 | 사용자는 암 신호 스펙트럼 수가 반복측정 참고값이며 신규 검사 판정에는 사용되지 않음을 이해해야 한다. | 참고값을 최종 판정으로 오해 | 시나리오 A/C | 평균 SSI와 반복측정 참고값의 역할을 구분해 설명 |

## 2. 화면/문서 용어 대응

| 내부 필드 | 사용자 표시 | 보고서 표시 | 비고 |
|---|---|---|---|
| `screening_index` / `ssi_score` | SSI 점수 | SSI 점수 | 사용자 표시값은 0-10 SSI 스케일 |
| `ssi_threshold` | 추가 확인 권고 경계 | 추가 확인 권고 경계 | 4.0은 중간 구간에 포함되며 초과 시 추가 확인 권고 |
| `model_probability_threshold` | 사용자 화면 미표시 | 사용자 화면 미표시 | STK-V2 내부 확률 기준값 θ=0.60 |
| `N_valid` | 유효 반복측정 수 | 유효 반복측정 수 | QC 통과 반복측정 수, 최소 3 |
| `majority_vote` | 암 신호 스펙트럼 수(참고) | 암 신호 스펙트럼 수(참고) | 호환성 필드로 유지되는 `n_detected/N_valid` 형식이며 신규 검사의 최종 판정에는 사용하지 않음 |
| `decision_level = positive` | 추가 확인 권고 | 추가 확인 권고 | 평균 SSI > 4.0, 진단 아님 |
| `decision_level = moderate` | 추가 평가 고려 | 추가 평가 고려 | 1.0 ≤ 평균 SSI ≤ 4.0 |
| `decision_level = negative` | 기준 미만 | 기준 미만 | 평균 SSI < 1.0, 정상 확정 아님 |
| `cancer_type_confidence` | 패턴 구분 수준 | 패턴 구분 수준 | 진단 신뢰도 아님 |
| `cancer_type_probabilities` | 암종별 패턴 비교 결과 | 암종별 패턴 비교 결과 | Cancer Type ID 상대 비교값 |
| `balanced` | 표준 판정 기준 | 표준 판정 기준 | 사용자 선택 mode로 노출하지 않음 |
