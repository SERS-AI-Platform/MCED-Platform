# SERS-AI 임상 웹앱 사용설명서

## 1. 목적

SERS-AI 임상 웹앱은 소변 SERS 스펙트럼 파일을 입력받아 모델 기반 암 선별 참고 지표를 제공하는 소프트웨어이다.

본 시스템의 결과는 최종 진단이 아니다. 결과는 임상 전문의의 판단과 추가 검사 필요성 검토를 보조하기 위한 참고 정보로 사용한다.

## 2. 대상 사용자

| 사용자 | 역할 |
|---|---|
| 임상의 | 환자 정보 입력, 스펙트럼 업로드, QC 및 본인 소유 결과 확인 |
| 임상의 | 분석 결과 확인, 보고서 검토, 추가 확인 필요성 판단 |
| 관리자 | 사용자 계정, 감사 로그, 시스템 상태 확인 |

## 3. 기본 용어

| 용어 | 의미 |
|---|---|
| 유효 반복측정 수 (`N_valid`) | QC를 통과해 환자 단위 판정에 사용된 반복측정 수 |
| 암 관련 신호 반복 수 (`n_detected`) | 유효 반복측정 중 암 관련 신호가 내부 기준 이상인 반복측정 수 |
| 평균 SSI | QC 통과 반복측정의 내부 암 관련 모델 신호값을 평균한 뒤 0-10 범위로 변환한 환자 단위 판정 점수 |
| 추가 확인 권고 | QC 유효 검사에서 평균 SSI가 4.0을 초과한 상태 |
| 추가 평가 고려 | QC 유효 검사에서 평균 SSI가 1.0 이상 4.0 이하인 상태 |
| 기준 미만 | QC 유효 검사에서 평균 SSI가 1.0 미만인 상태 |
| 암종 분류 점수 | 여러 암종 중 어떤 암종 패턴과 더 비슷한지 10점 척도로 나타낸 보조값 |

`추가 확인 권고`는 암 진단 또는 강한 양성을 의미하지 않는다. `기준 미만`은 정상 확정 또는 암 없음 확정을 의미하지 않는다.

내부 계산값과 내부 확률 기준값은 사용자가 변경할 수 없다. QC 유효 검사에서는 평균 SSI가 4.0을 초과하면 `추가 확인 권고`, 1.0 이상 4.0 이하이면 `추가 평가 고려`, 1.0 미만이면 `기준 미만`으로 판정한다. 반복측정별 암 신호 스펙트럼 수는 참고 정보이며 신규 검사의 최종 판정에는 사용하지 않는다.

## 4. 사용 전 준비

1. 시스템이 실행 중인지 확인한다.
2. 사용자 계정으로 로그인한다.
3. 분석할 환자 ID, 나이, 성별, 필요 시 BMI를 준비한다.
4. 환자당 반복 측정 스펙트럼 CSV 파일을 준비한다.
5. CSV는 파수(wavenumber)와 강도(intensity) 2열 구조여야 한다.

## 5. 사용 절차

### 5.1 로그인

1. 사용자 ID와 비밀번호를 입력한다.
2. 로그인 후 환자 정보 입력 화면으로 이동한다.

기존의 운영 모드 선택 단계는 사용하지 않는다. 시스템은 모델에 정의된 표준 판정 기준을 자동 적용한다.

### 5.2 환자 정보 입력

1. 환자번호를 입력한다.
2. 나이를 입력한다.
3. 성별을 선택한다.
4. BMI가 있으면 입력한다. 없으면 생략할 수 있다.
5. `다음`을 선택한다.

성별 정보는 생물학적으로 불가능한 암종 표시를 제한하는 데 사용될 수 있다.

### 5.3 스펙트럼 업로드

1. CSV 파일을 업로드 영역에 드래그하거나 클릭하여 선택한다.
2. 환자당 반복 측정 5개 파일을 등록한다.
3. QC를 통과한 유효 반복측정이 3개 미만이면 결과를 표시하지 않는다.
4. 파일 목록을 확인한다.
5. `분석 시작`을 선택한다.

### 5.4 QC 확인

시스템은 업로드된 스펙트럼에 대해 품질 관리를 수행한다.

| QC 항목 | 의미 |
|---|---|
| 강도 기준 | 신호 강도가 분석 가능한 수준인지 확인 |
| 스파이크 잡음 | 한 지점에 비정상적으로 큰 순간 잡음이 있는지 확인 |
| 포화 | 검출기 최대 범위에서 신호가 잘려 평평해졌는지 확인 |
| 반복 상관 계수 | 반복 측정 간 일관성을 확인 |

5개 중 3개 이상이 QC를 통과하더라도 강도 부족, 스파이크 잡음 또는 포화가 하나라도 확인되면 검사 무효로 처리하며 분석 결과를 표시하지 않는다. 동일 검체 재측정 또는 신규 검체 재채취가 필요하다. 상관계수 미달만 있는 경우에는 `N_valid`가 3 이상이면 결과 확인을 진행할 수 있다.

### 5.5 결과 확인

결과 화면에는 다음 항목이 표시된다.

| 항목 | 해석 |
|---|---|
| SSI 점수 | 유효 반복측정별 내부 암 관련 신호값의 평균을 0-10으로 변환한 환자 단위 판정 점수 |
| 유효 반복측정 수 | 환자 단위 판정에 사용된 QC 통과 반복측정 수 (`N_valid`) |
| 내부 기준 초과 반복 수 | 유효 반복측정 중 내부 기준을 초과한 반복 수 (`n_detected/N_valid`) |
| SSI 판정 경계 | 1.0과 4.0. 1.0과 4.0은 모두 `추가 평가 고려` 구간에 포함 |
| 추가 확인 권고 / 추가 평가 고려 / 기준 미만 | 평균 SSI 3단계 기준에 따른 최종 선별 결과 |
| 가장 비슷한 암종 패턴 | 추가 확인 권고 시 Cancer Type ID가 비교한 최상위 암종 패턴 |
| 암종별 패턴 비교 결과 | 암종별 상대 비교값 |
| 반복 측정 상세 | 각 반복 측정의 SSI 점수, 암 신호 있음/없음과 QC 정보 |

QC를 통과한 반복측정이 3개 이상이고 중대한 QC 실패가 없어 검사가 유효한 경우에만 평균 SSI를 이용해 최종 선별 조치 문구를 결정한다. 암 신호 스펙트럼 수(`n_detected/N_valid`)는 반복측정 참고값이며 최종 판정 기준이 아니다.

가장 비슷한 암종 패턴과 암종 분류 점수는 추가 확인 권고 상태에서만 보조 정보로 표시한다. 시스템은 유효 반복측정의 암종별 상대 분류값을 평균하고, 남성에서는 난소암을, 여성에서는 전립선암을 제외한 뒤 남은 값을 다시 정규화한다. 그중 가장 큰 값을 최상위 암종으로 선택하고 10점 척도 점수를 함께 표시한다. 암종별 패턴 비교값과 점수는 암종별 진단 확률이 아니라 어떤 기준 패턴과 상대적으로 더 비슷한지 보여주는 참고값이다.

### 5.6 보고서 생성

1. 결과 화면에서 `보고서 생성`을 선택한다.
2. 보고서에는 환자 정보, 검사 조건, QC 요약, 분석 결과가 포함된다.
3. 보고서 생성 기록은 감사 추적 로그에 저장된다.

## 6. 결과 해석 원칙

| 화면 표시 | 권장 해석 |
|---|---|
| 추가 확인 권고 | 임상적 맥락과 필요 시 추가 검사를 검토한다. |
| 기준 미만 | 본 검사 기준에서는 추가 확인 권고 수준에 도달하지 않았다. 증상 또는 임상 판단에 따라 추가 평가가 필요할 수 있다. |
| 패턴 구분이 비교적 뚜렷함 | Cancer Type ID에서 특정 암종 패턴과 상대적으로 더 비슷하게 나타났다. 최종 진단은 아니다. |

## 7. 금기 또는 제한

- 본 시스템을 단독 진단 근거로 사용하지 않는다.
- SSI 점수를 강한 양성/약한 양성 등급으로 해석하지 않는다.
- 내부 평균확률, 내부 임계값 또는 암종별 분류 점수를 질환의 절대 발생확률로 해석하지 않는다.
- QC 실패 스펙트럼을 근거로 결과를 해석하지 않는다.
- 환자 식별 정보와 결과 보고서는 기관 보안 절차에 따라 관리한다.

## 8. 오류 대응

| 상황 | 조치 |
|---|---|
| 로그인 실패 | 사용자 ID/비밀번호를 확인한다. |
| CSV 업로드 실패 | 파일 확장자와 2열 구조를 확인한다. |
| 모든 스펙트럼 QC 실패 | 재측정 후 다시 업로드한다. |
| 보고서 생성 실패 | 관리자에게 오류 메시지와 시간 정보를 전달한다. |

## 9. 감사 추적

시스템은 로그인, 환자 세션 생성, 스펙트럼 업로드, 분석 완료, 보고서 생성 등 주요 행위를 기록한다. 감사 로그는 결과 해석이 아니라 사용 이력 확인 목적이다.

## 10. 모델 판정 기준 및 내부 성능 근거

| 항목 | 내용 |
|---|---|
| 모델 | uSERS-Net Ver1 |
| 고정 내부 임계값 | θ=0.60. 검증셋에서 선택한 0.5999를 제품 설정값 0.60으로 고정 |
| 성능평가 코호트 | 총 1,628명: Train 976명(암 719, 비암 257), Validation 324명(암 239, 비암 85), Test 328명(암 241, 비암 87) |
| 암 선별 성능 | 고정 테스트셋 328명에서 민감도 94.61%(228/241), 특이도 96.55%(84/87), AUROC 0.9925 |
| Cancer Type ID(TOO) 성능 | 고정 테스트셋의 기지 암 환자 241명에서 정확도 98.34%(237/241), macro-F1 0.9593 |

암종별 F1과 평가 인원은 전립선암 1.0000(n=20), 폐암 0.9836(n=60), 대장암 1.0000(n=60), 췌장암 0.9474(n=20), 난소암 1.0000(n=14), 유방암 0.8000(n=6), 방광암 0.9839(n=61)이다.

주: 위 성능은 환자별 반복 스펙트럼을 특징 단계에서 평균 집계한 후향적 내부 고정 분할 평가에서 산출한 추정치이며, 배포 웹앱의 평균 SSI 3단계 판정 전체 파이프라인을 직접 평가한 수치가 아니다. 암군과 비암군의 모집기관 차이에 따른 병원 교란 가능성이 있으므로 기관 간 일반화 성능을 입증하지 않는다. 실제 임상 사용 성능과 일반화 가능성은 독립된 외부 임상 검증을 통해 별도로 확인해야 한다.
