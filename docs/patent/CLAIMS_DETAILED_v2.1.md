## IP-1: 계층적 다질환 스크리닝 시스템 (Umbrella Patent)

### 독립항 1 (방법 청구항)

생체 시료로부터 획득한 분광 스펙트럼 데이터를 이용하여 복수의 질환을 스크리닝하는 방법으로서,

(a) 동일 시료에 대해 복수 회(n ≥ 2) 반복 측정된 스펙트럼 데이터를 수신하고, 상기 반복 측정된 스펙트럼 중 사전 정의된 품질 기준을 충족하지 않는 스펙트럼을 제거하는 품질 관리 단계;

(b) 상기 품질 관리 단계를 통과한 복수의 스펙트럼에 대해, 파수(wavenumber) 축 상에서 산술 평균을 산출하여 피검자별 단일 대표 스펙트럼을 생성하는 통합 단계;

(c) 상기 대표 스펙트럼으로부터 특징 벡터를 추출하는 특징 추출 단계;

(d) 상기 특징 벡터를 제1 분류 모델에 입력하여, 질환 존재 확률(p_det)을 산출하고, 상기 질환 존재 확률이 사전 정의된 제1 임계값(θ₁)을 초과하는지 여부에 따라 양성 또는 음성을 판별하는 질환 검출 단계;

(e) 상기 질환 검출 단계에서 양성으로 판별된 피검자에 대해, 상기 특징 벡터를 제2 분류 모델에 입력하여 k종(k ≥ 2) 질환 각각에 대한 아형 확률 벡터(p₁, p₂, ..., p_k)를 산출하고, 최대 확률을 갖는 질환 아형을 식별하는 질환 아형 식별 단계;

를 포함하되,

상기 제1 분류 모델과 상기 제2 분류 모델은 별도로 학습되며, 상기 제1 분류 모델은 질환군 및 비질환군 전체를 학습 데이터로 사용하고, 상기 제2 분류 모델은 질환군 데이터만을 학습 데이터로 사용하는 것을 특징으로 하는 계층적 다질환 스크리닝 방법.

### 독립항 2 (시스템 청구항)

프로세서 및 메모리를 포함하는 컴퓨팅 장치에서 실행되는 다질환 스크리닝 시스템으로서,

(a) 분광 측정 장치로부터 피검자별 복수의 반복 측정 스펙트럼을 수신하는 데이터 수신 모듈;

(b) 수신된 스펙트럼에 대해 계층적 품질 검사를 수행하여 부적합 스펙트럼을 식별하는 품질 관리 모듈;

(c) 적합 스펙트럼을 통합하여 피검자별 대표 특징 벡터를 생성하는 전처리 모듈;

(d) 상기 대표 특징 벡터를 입력으로 하여 질환 유무를 판별하는 제1 분류 모듈;

(e) 제1 분류 모듈에서 양성 판별된 피검자의 특징 벡터를 입력으로 하여 질환 아형을 식별하는 제2 분류 모듈;

(f) 상기 질환 존재 확률 및 아형 확률을 임상 점수로 변환하여 출력하는 점수 변환 모듈;

을 포함하는 다질환 스크리닝 시스템.

### 독립항 3 (컴퓨터 판독 가능 기록매체)

프로세서에 의해 실행될 때, 독립항 1의 방법을 수행하도록 하는 명령어를 저장한 컴퓨터 판독 가능한 비일시적 기록매체.

### 종속항 그룹

**종속항 1** (Late Fusion — IP-5 분할출원 기반)
독립항 1에 있어서,
상기 제1 분류 모델은 분광 스펙트럼 데이터만을 입력으로 사용하여 학습되고,
상기 제2 분류 모델은 분광 스펙트럼 데이터 및 임상 메타데이터를 연결(concatenate)한 융합 특징 벡터를 입력으로 사용하여 학습되되,
상기 임상 메타데이터는 피검자의 연령, 성별, 및 체질량지수(BMI) 중 하나 이상을 포함하며,
상기 제1 분류 모델의 학습 시 임상 메타데이터를 의도적으로 배제함으로써, 인구통계학적 교란 변수에 의한 과적합을 방지하는 것을 특징으로 하는 방법.

**종속항 2** (Sex Constraint)
독립항 1에 있어서,
상기 질환 아형 식별 단계는 피검자의 생물학적 속성을 참조하여, 해당 피검자에게 생물학적으로 발생 불가능한 질환 아형의 확률을 0으로 설정하고, 나머지 아형의 확률을 합이 1이 되도록 재정규화(renormalize)하는 사후 보정 단계를 더 포함하되,
상기 생물학적 속성이 성별인 경우, 남성 피검자에 대해 난소암 확률을 0으로 설정하고 여성 피검자에 대해 전립선암 확률을 0으로 설정하는 것을 특징으로 하는 방법.

**종속항 3** (Mean Aggregation)
독립항 1에 있어서,
상기 통합 단계의 산술 평균은 다음과 같이 정의되는 것을 특징으로 하는 방법:
각 파수 지점 ν_j (j = 1, 2, ..., L)에 대해, 적합 스펙트럼 {s₁(ν_j), s₂(ν_j), ..., s_m(ν_j)}의 산술 평균 s̄(ν_j) = (1/m) × Σᵢ sᵢ(ν_j)를 산출하여 대표 스펙트럼 S̄ = [s̄(ν₁), s̄(ν₂), ..., s̄(ν_L)]을 구성.

**종속항 4** (Fixed Grid Interpolation)
독립항 1에 있어서,
상기 특징 추출 단계 전에, 각 스펙트럼을 사전 정의된 N개(N ≥ 500)의 등간격 파수 지점으로 보간(interpolation)하는 표준화 단계를 더 포함하되,
상기 보간은 측정 장비의 파수 해상도 차이를 보정하여 동일 차원의 특징 벡터를 생성하는 것을 특징으로 하는 방법.

**종속항 5** (Multi-view — IP-6 분할출원 기반)
독립항 1에 있어서,
상기 특징 추출 단계는:
(c-1) 대표 스펙트럼을 제1 뷰로 사용하는 단계;
(c-2) 상기 대표 스펙트럼의 파수에 대한 1차 도함수를 수치적으로 산출하여 제2 뷰를 생성하는 단계;
(c-3) 상기 1차 도함수의 파수에 대한 도함수를 수치적으로 산출하여 제3 뷰를 생성하는 단계;
(c-4) 각 뷰를 독립적으로 정규화한 후 연결(concatenate)하여 다중 뷰 특징 벡터를 구성하는 단계;
를 포함하되,
상기 제1 뷰는 피크 강도 정보를, 상기 제2 뷰는 피크 위치 및 기울기 변화 정보를, 상기 제3 뷰는 피크 곡률 및 형상 정보를 각각 인코딩하여, 단일 뷰 대비 질환 분류 성능이 향상되는 것을 특징으로 하는 방법.

**종속항 6** (비질환 대조군 구성)
독립항 1에 있어서,
상기 제1 분류 모델의 학습에 사용되는 비질환군은 건강 정상인, 당뇨병 환자, 고혈압 환자, 및 혈액 투석 환자 중 둘 이상을 포함하여, 만성질환에 의한 대사체 변화와 암에 의한 대사체 변화를 구분하도록 학습되는 것을 특징으로 하는 방법.

**종속항 7** (질환 아형 범위)
독립항 1에 있어서,
k ≥ 5이고, 상기 질환 아형은 전립선암, 유방암, 난소암, 폐암, 대장암, 췌장암, 및 방광암 중 5종 이상을 포함하는 것을 특징으로 하는 방법.

**종속항 8** (아형별 신뢰도 임계값)
독립항 1에 있어서,
상기 질환 아형 식별 단계는, 각 질환 아형 c_j (j = 1, ..., k)에 대해 개별적으로 정의된 제2 임계값(θ₂_j)을 적용하되, 식별된 아형의 확률이 해당 아형의 제2 임계값 미만인 경우, "아형 미확정(indeterminate)"으로 분류하는 단계를 더 포함하는 것을 특징으로 하는 방법.

**종속항 9** (학습 방법 — 클래스 불균형 처리)
독립항 1에 있어서,
상기 제1 분류 모델 및 제2 분류 모델의 학습 시, 각 클래스의 샘플 수에 반비례하는 가중치를 부여하는 클래스 균형(class-balanced) 학습을 수행하되,
상기 제1 분류 모델은 양성 클래스 가중치로 (비질환군 수 / 질환군 수)를 사용하고,
상기 제2 분류 모델은 각 아형의 유효 샘플 수(effective number)에 기반한 클래스별 가중치를 사용하는 것을 특징으로 하는 방법.

**종속항 10** (분광법 한정)
독립항 1에 있어서,
상기 분광 스펙트럼 데이터는 표면증강라만분광법(SERS), 라만분광법, 적외선흡수분광법, 또는 형광분광법 중 하나에 의해 획득되고,
상기 생체 시료는 소변, 혈액, 혈청, 혈장, 타액, 또는 뇌척수액 중 하나인 것을 특징으로 하는 방법.

**종속항 11** (데이터 증강)
독립항 1에 있어서,
상기 제1 분류 모델 및 제2 분류 모델의 학습 시, 학습용 스펙트럼에 대해:
(i) 표준편차 σ ≤ 0.05인 가우시안 노이즈를 부가하는 노이즈 증강;
(ii) [0.9, 1.1] 범위의 무작위 스케일링 계수를 곱하는 스케일 증강; 및
(iii) 파수 축 방향으로 ±δ (δ ≤ 5) 포인트 이내의 무작위 이동을 적용하는 시프트 증강;
중 하나 이상을 적용하는 데이터 증강 단계를 더 포함하는 것을 특징으로 하는 방법.

## IP-3: SSI (SERS Screening Index) 임상 점수 변환

### 독립항 1 (방법 청구항)

분류 모델의 질환 확률 출력을 임상 현장에서 해석 가능한 점수로 변환하는 방법으로서,

(a) 분류 모델로부터 피검자의 질환 존재 확률 p (0 ≤ p ≤ 1)를 수신하는 단계;

(b) 상기 분류 모델의 운영 모드에 대응하는 운영 임계값 θ (0 < θ < 1)를 수신하는 단계;

(c) 사전 정의된 양성 판정 기준 점수 C (0 < C < N)와 최대 점수 N을 설정하는 단계;

(d) 상기 질환 확률 p를 다음의 구간별 선형 변환(piecewise linear transformation)에 의해 임상 점수 S (0 ≤ S ≤ N)로 변환하는 단계:

> p ≤ θ인 경우: S = C × (p / θ)
> p > θ인 경우: S = C + (N - C) × (p - θ) / (1 - θ)

를 포함하되,

상기 변환은 (i) 단조 증가(strictly monotonic increasing)이고, (ii) 순위 보존(rank-preserving)이며, (iii) 역변환 가능(invertible)하여, 변환 전후의 ROC-AUC, 민감도, 및 특이도가 동일하게 유지되는 것을 특징으로 하는 점수 변환 방법.

### 독립항 2 (시스템 청구항)

분류 모델의 출력을 임상 점수로 변환하는 점수 변환 장치로서,

(a) 분류 모델로부터 질환 확률 p를 수신하는 입력부;
(b) 운영 모드별 임계값 θ를 저장하는 저장부;
(c) 상기 질환 확률 p와 임계값 θ로부터 구간별 선형 변환을 수행하여 임상 점수 S를 산출하는 연산부;
(d) 상기 임상 점수 S에 기초하여 위험도 등급을 결정하는 등급 판정부;
(e) 상기 임상 점수 및 위험도 등급을 출력하는 출력부;

를 포함하는 점수 변환 장치.

### 종속항 그룹

**종속항 1** (구체적 수치 범위)
독립항 1에 있어서,
N = 10이고, C = 4.0이며,
상기 변환은 p = θ일 때 S = 4.0을 만족하고,
상기 구간별 선형 변환의 각 구간에서의 기울기는:
- 하위 구간(p ≤ θ): dS/dp = 4.0 / θ
- 상위 구간(p > θ): dS/dp = 6.0 / (1 - θ)
인 것을 특징으로 하는 방법.

**종속항 2** (5단계 위험도 층화)
독립항 1에 있어서,
상기 임상 점수 S에 기초하여 피검자를 복수의 위험도 등급으로 분류하는 위험도 층화 단계를 더 포함하되,
상기 위험도 등급은:
- 저위험(LOW): 0.0 ≤ S < 2.0
- 저-중위험(LOW_MODERATE): 2.0 ≤ S < 4.0
- 중위험(MODERATE): 4.0 ≤ S < 6.0
- 고위험(HIGH): 6.0 ≤ S < 8.0
- 초고위험(VERY_HIGH): 8.0 ≤ S ≤ 10.0
의 5단계로 정의되는 것을 특징으로 하는 방법.

**종속항 3** (역변환)
독립항 1에 있어서,
임상 점수 S로부터 원래의 질환 확률 p를 복원하는 역변환 단계를 더 포함하되,
상기 역변환은:
- S ≤ C인 경우: p = θ × (S / C)
- S > C인 경우: p = θ + (1 - θ) × (S - C) / (N - C)
로 정의되어, 순방향 변환과 역변환의 합성이 항등 함수를 만족하는 것을 특징으로 하는 방법.

**종속항 4** (복수 운영 모드)
독립항 1에 있어서,
상기 운영 임계값 θ는 복수의 운영 모드 중 선택된 하나에 대응하되,
상기 복수의 운영 모드는:
- 스크리닝 모드: 높은 민감도를 위한 낮은 임계값 (θ_screening < θ_balanced);
- 균형 모드: 민감도와 특이도의 균형을 위한 중간 임계값 (θ_balanced);
- 확인 모드: 높은 특이도를 위한 높은 임계값 (θ_confirmation > θ_balanced);
을 포함하되,
모든 운영 모드에서 동일한 구간별 선형 변환 함수가 사용되고 임계값만 변경되며, 모든 모드에서 S = C가 양성/음성 경계점으로 고정되는 것을 특징으로 하는 방법.

**종속항 5** (아형별 점수 변환)
독립항 1에 있어서,
질환 아형 분류 모델의 출력인 아형별 확률 벡터 (p₁, p₂, ..., p_k)에 대해, 각 아형 확률을 독립적으로 선형 스케일링하여 아형별 점수(CTI_j = p_j × N)를 산출하는 아형 점수 변환 단계를 더 포함하는 것을 특징으로 하는 방법.

**종속항 6** (출력 정밀도)
독립항 1에 있어서,
상기 임상 점수 S는 소수점 첫째 자리까지 표시(0.1 단위)되어, 임상의에게 연속적인 위험도 정보를 직관적으로 전달하는 것을 특징으로 하는 방법.

**종속항 7** (선행 기술 대비 특징)
독립항 1에 있어서,
상기 구간별 선형 변환은, 임계값 θ가 변경되더라도 양성 판정 기준 점수 C가 고정(anchor)됨으로써, 상이한 운영 모드 간에 임상의의 점수 해석 기준이 일관되게 유지되는 것을 특징으로 하는 방법.

## IP-4: 3단계 자동 QC Pipeline

### 독립항 1 (방법 청구항)

분광 분석 기반 진단 시스템에서 반복 측정 스펙트럼의 신뢰성을 계층적으로 평가하는 품질 관리 방법으로서,

(a) 동일 시료에 대해 복수 회(n ≥ 2) 반복 측정된 스펙트럼 데이터 {s₁(ν), s₂(ν), ..., s_n(ν)}를 수신하는 단계 — 여기서 ν는 파수(wavenumber) 축 상의 위치를 나타냄;

(b) **제1 품질 검사(강도 게이트):** 각 스펙트럼 sᵢ(ν)에 대해 사전 정의된 지문 영역(fingerprint region) [ν_lo, ν_hi] 내의 평균 절대 강도 Ī_i를 산출하고, 전체 측정 배치의 상기 평균 강도들의 중앙값(M_batch)을 산출한 후, Ī_i < α × M_batch인 스펙트럼을 무효(enhancement failure)로 판정하여 제거하는 단계 — 여기서 α는 사전 정의된 강도 게이트 비율(0 < α < 1);

(c) **제2 품질 검사(재현성 검증):** 상기 제1 품질 검사를 통과한 스펙트럼들에 대해, 각 파수 지점 ν_j에서의 표준편차 σ(ν_j)를 산출하고(자유도 보정 적용, ddof=1), 최대 강도 I_max = max(s̄(ν))로 정규화한 상대표준편차 RSD(ν_j) = σ(ν_j) / I_max × 100을 파수별로 산출한 후, 전체 파수에 대한 평균 RSD(mean_RSD)가 사전 정의된 상한 β를 초과하는 경우 부적합으로 판정하는 단계;

(d) **제3 품질 검사(형상 일관성 검증):** 상기 제1 품질 검사를 통과한 스펙트럼들의 모든 쌍(pair)에 대해 피어슨 상관계수 r(sᵢ, sⱼ) = corr(sᵢ(ν), sⱼ(ν))를 산출하고, 평균 상관계수(mean_corr) 및 최소 상관계수(min_corr)를 산출한 후, mean_corr이 사전 정의된 하한 γ 미만인 경우 부적합으로 판정하는 단계;

(e) 상기 제2 품질 검사 및 제3 품질 검사 중 어느 하나라도 부적합인 시료를 식별하고, 부적합 사유를 기록하는 단계;

(f) 상기 모든 품질 검사를 통과한 스펙트럼만을 후속 분류 분석에 사용하는 단계;

를 포함하되,

상기 제1 품질 검사는 개별 스펙트럼 수준(per-spectrum)에서 수행되고, 상기 제2 및 제3 품질 검사는 시료 수준(per-sample)에서 수행되며, 상기 세 단계의 검사가 상이한 품질 결함(신호 부재, 강도 변동, 형상 변형)을 각각 독립적으로 검출하는 것을 특징으로 하는 계층적 품질 관리 방법.

### 독립항 2 (시스템 청구항)

분광 측정 시스템과 연결되어 측정 데이터의 품질을 자동으로 평가하는 품질 관리 장치로서,

(a) 반복 측정된 스펙트럼 데이터를 수신하는 입력부;
(b) 각 스펙트럼의 지문 영역 평균 강도를 산출하고, 배치 중앙값 대비 비율로 무효 스펙트럼을 판정하는 강도 게이트 모듈;
(c) 적합 스펙트럼 간의 상대표준편차를 파수별로 산출하여 재현성을 평가하는 RSD 모듈;
(d) 적합 스펙트럼 간의 쌍별 피어슨 상관계수를 산출하여 형상 일관성을 평가하는 상관 분석 모듈;
(e) 부적합 시료의 재측정을 요청하거나, 적합 시료만을 후속 처리로 전달하는 출력부;

를 포함하는 품질 관리 장치.

### 종속항 그룹

**종속항 1** (구체적 임계값)
독립항 1에 있어서,
상기 강도 게이트 비율 α는 0.1이고, 상기 지문 영역은 400 cm⁻¹ 내지 2200 cm⁻¹이며, 상기 RSD 상한 β는 5.0%이고, 상기 상관계수 하한 γ는 0.95인 것을 특징으로 하는 방법.

**종속항 2** (적응적 임계값)
독립항 1에 있어서,
상기 강도 게이트의 임계값은 동일 측정 배치 내 전체 스펙트럼의 평균 강도 분포로부터 적응적으로 결정되어, 측정 조건(기판 로트, 레이저 출력, 시료 농도)의 변동에 자동으로 대응하는 것을 특징으로 하는 방법.

**종속항 3** (RSD 정규화 방식)
독립항 1에 있어서,
상기 RSD 산출 시, 분모로 파수별 평균값 대신 최대 강도 I_max를 사용하되, 이는 베이스라인 보정된 스펙트럼에서 평균값이 0에 근접하는 파수 영역에서의 발산(divergence)을 방지하기 위함인 것을 특징으로 하는 방법.

**종속항 4** (부적합 시 처리)
독립항 1에 있어서,
상기 (e) 단계에서 부적합으로 판정된 시료에 대해, 부적합 사유(강도 부족, 높은 RSD, 낮은 상관계수)를 분류별로 기록하고, 해당 시료의 재측정을 자동으로 요청하는 단계를 더 포함하는 것을 특징으로 하는 방법.

**종속항 5** (이상치 검출)
독립항 1에 있어서,
상기 제1 품질 검사 전에, 각 스펙트럼의 평균 강도 또는 최대 강도에 대한 Z-스코어 (|z| = |값 - 평균| / 표준편차)를 산출하고, |z| > 3.0인 스펙트럼을 이상치(outlier)로 식별하는 단계를 더 포함하는 것을 특징으로 하는 방법.

**종속항 6** (대표 스펙트럼 선택)
독립항 1에 있어서,
모든 품질 검사를 통과한 스펙트럼 중에서, 쌍별 거리(상관 거리, 유클리드 거리, 또는 코사인 거리)의 합이 최소인 스펙트럼을 대표 스펙트럼(medoid)으로 선택하는 단계를 더 포함하는 것을 특징으로 하는 방법.

**종속항 7** (SERS 한정)
독립항 1에 있어서,
상기 분광 분석은 표면증강라만분광법(SERS)이고, 상기 반복 측정은 동일 SERS 기판의 상이한 측정 위치(spot)에서 수행되며, 상기 지문 영역은 400 cm⁻¹ 내지 2200 cm⁻¹인 것을 특징으로 하는 방법.

**종속항 8** (수렴 분석)
독립항 1에 있어서,
반복 측정 횟수 n을 2부터 최대 가용 횟수까지 순차적으로 증가시키면서 mean_RSD 및 mean_corr의 변화를 추적하고, 상기 지표들이 사전 정의된 수렴 기준을 충족하는 최소 반복 횟수를 결정하는 수렴 분석 단계를 더 포함하는 것을 특징으로 하는 방법.

## IP-5: 계층적 Multimodal Late Fusion

### 독립항 1 (방법 청구항)

복수 종류의 데이터 모달리티를 이용하여 질환을 계층적으로 분류하는 방법으로서,

(a) 피검자로부터 제1 모달리티 데이터(분광 스펙트럼 데이터) 및 제2 모달리티 데이터(임상 메타데이터)를 각각 획득하는 단계;

(b) 상기 제1 모달리티 데이터만을 입력으로 사용하여 학습된 제1 분류 모델에 상기 제1 모달리티 데이터를 입력하여, 질환 유무를 판별하는 질환 검출 단계;

(c) 상기 제1 분류 모델에서 양성으로 판별된 피검자에 대해, 상기 제1 모달리티 데이터로부터 추출된 특징 벡터 F₁ (차원 d₁)과 상기 제2 모달리티 데이터로부터 추출된 특징 벡터 F₂ (차원 d₂)를 연결(concatenate)하여 융합 특징 벡터 F_fused = [F₁; F₂] (차원 d₁ + d₂)를 생성하는 단계;

(d) 상기 융합 특징 벡터를 제2 분류 모델에 입력하여 k종(k ≥ 2) 질환 아형 각각에 대한 확률을 산출하는 질환 아형 식별 단계;

를 포함하되,

상기 제1 분류 모델은 제1 모달리티 데이터만으로 학습되고, 상기 제2 분류 모델은 질환군의 융합 특징 벡터로 학습되며,
상기 계층적 구조에 의해 질환 검출 단계에서는 임상 메타데이터에 의한 교란(confounding)이 배제되고, 질환 아형 식별 단계에서는 임상 정보의 보완적 판별력이 활용되는 것을 특징으로 하는 계층적 다중모달 분류 방법.

### 종속항 그룹

**종속항 1** (임상 메타데이터 구성)
독립항 1에 있어서,
상기 제2 모달리티 데이터는 피검자의 연령(연속값), 성별(이진값: 0 또는 1), 및 체질량지수(BMI, 연속값)를 포함하는 3차원 특징 벡터이며,
상기 BMI 값 중 사전 정의된 상한(예: 60)을 초과하는 이상값은 결측치로 처리하고, 결측치는 학습 데이터의 중앙값으로 대체(imputation)하는 것을 특징으로 하는 방법.

**종속항 2** (교란 변수 배제 근거)
독립항 1에 있어서,
상기 제1 분류 모델의 학습 시 제2 모달리티를 배제하는 것은, 연령, 성별, 또는 BMI가 질환 유병률과 상관관계를 가짐으로써 모달리티 자체의 판별력이 아닌 인구통계학적 편향에 의한 과적합을 유발할 수 있기 때문이며,
상기 제2 분류 모델에서만 제2 모달리티를 도입하는 것은, 이미 질환으로 판별된 피검자군 내에서는 인구통계학적 변수가 암종 간 분포 차이(예: 전립선암의 남성 편향, 난소암의 여성 편향)를 반영하여 보완적 판별력을 제공하기 때문인 것을 특징으로 하는 방법.

**종속항 3** (임계값 최적화)
독립항 1에 있어서,
상기 질환 검출 단계의 임계값 θ₁은, 검증 데이터셋에서 수신자 조작 특성 곡선(ROC)의 진양성률(TPR)에서 위양성률(FPR)을 뺀 값(Youden's J index = TPR - FPR)이 최대인 지점의 확률값으로 결정되는 것을 특징으로 하는 방법.

**종속항 4** (모달리티 간 상호작용 학습)
독립항 1에 있어서,
상기 (c) 단계의 특징 융합은 단순 연결(concatenation) 대신,
(i) 교차 어텐션(cross-attention) 메커니즘에 의해 제1 모달리티 특징이 제2 모달리티를 질의(query)하여 상호 관련 특징을 강조하는 방식; 또는
(ii) FiLM(Feature-wise Linear Modulation)에 의해 제2 모달리티가 제1 모달리티의 특징 맵에 대한 스케일(scale) 및 시프트(shift) 파라미터를 생성하는 방식;
중 하나를 사용하는 것을 특징으로 하는 방법.

**종속항 5** (단계별 모델 독립성)
독립항 1에 있어서,
상기 제1 분류 모델과 제2 분류 모델은 상이한 모델 아키텍처, 하이퍼파라미터, 또는 학습 전략을 독립적으로 사용할 수 있으며,
상기 제1 분류 모델은 선형 모델(로지스틱 회귀)이고, 상기 제2 분류 모델은 비선형 모델(신경망)이거나, 또는 그 반대인 것을 특징으로 하는 방법.

## IP-6: Multi-view Spectral Feature Representation

### 독립항 1 (방법 청구항)

분광 스펙트럼 데이터로부터 질환 분류를 위한 다중 뷰 특징 벡터를 생성하는 방법으로서,

(a) L개의 파수 지점으로 구성된 원시 스펙트럼 벡터 S₀ = [s(ν₁), s(ν₂), ..., s(ν_L)]을 제1 뷰로 획득하는 단계;

(b) 상기 원시 스펙트럼의 파수에 대한 1차 수치 도함수를 산출하여 제2 뷰 S₁ = [∂s/∂ν|_ν₁, ∂s/∂ν|_ν₂, ..., ∂s/∂ν|_ν_L]을 생성하는 단계 — 여기서 ∂s/∂ν|_νⱼ는 파수 지점 νⱼ에서의 중심차분(central difference) 또는 수치 기울기(numerical gradient)로 산출됨;

(c) 상기 1차 도함수의 파수에 대한 수치 도함수를 산출하여 제3 뷰 S₂ = [∂²s/∂ν²|_ν₁, ..., ∂²s/∂ν²|_ν_L]을 생성하는 단계;

(d) 각 뷰에 대해 독립적으로 정규화를 수행하는 단계:
각 뷰 S_c (c = 0, 1, 2)에 대해, 평균 μ_c = mean(S_c) 및 표준편차 σ_c = std(S_c)를 산출하고,
σ_c > ε (ε는 사전 정의된 미소값)인 경우 S̃_c = (S_c - μ_c) / σ_c로 정규화하고,
σ_c ≤ ε인 경우 S̃_c = S_c - μ_c로 중심화(centering)만 수행하는 단계;

(e) 정규화된 3개의 뷰를 연결(concatenate)하여 다중 뷰 특징 벡터 F_mv = [S̃₀; S̃₁; S̃₂] (차원 3L)을 구성하는 단계;

(f) 상기 다중 뷰 특징 벡터를 분류 모델에 입력하여 질환을 분류하는 단계;

를 포함하되,

상기 제1 뷰(원시 스펙트럼)는 각 파수에서의 절대 강도 정보를 인코딩하고,
상기 제2 뷰(1차 도함수)는 스펙트럼 기울기 변화에 의해 피크의 위치 및 어깨(shoulder) 구조를 강조하며,
상기 제3 뷰(2차 도함수)는 스펙트럼 곡률에 의해 피크의 폭, 첨도(sharpness), 및 중첩 피크의 분리를 인코딩하여,
단일 뷰(원시 스펙트럼만) 대비 질환 분류 성능이 향상되는 것을 특징으로 하는 다중 뷰 스펙트럼 특징 생성 방법.

### 종속항 그룹

**종속항 1** (피크 피팅 추가 뷰)
독립항 1에 있어서,
상기 (e) 단계의 다중 뷰 특징 벡터에, 스펙트럼의 사전 정의된 M개 피크 영역에 대해 Voigt 프로파일 피팅(Voigt profile fitting)을 수행하여 추출된 피크 파라미터를 추가 뷰로 연결하는 단계를 더 포함하되,
상기 피크 파라미터는 각 피크에 대해 (i) 피크 면적, (ii) 피크 높이, (iii) 반치전폭(FWHM), 및 (iv) 피크 위치 이동량(Δν)의 4개 값을 포함하고,
상기 Voigt 프로파일은 가우시안 성분(σ)과 로렌츠 성분(γ)의 합성곱(convolution)으로 정의되어, 비균일 확장(inhomogeneous broadening)과 자연 선폭(natural linewidth)을 동시에 모델링하는 것을 특징으로 하는 방법.

**종속항 2** (선형 모델과의 시너지)
독립항 1에 있어서,
상기 분류 모델은 선형 모델(로지스틱 회귀, 서포트 벡터 머신 등)이며,
상기 다중 뷰 구성에 의해, 원시 스펙트럼에서는 비선형적으로만 분리 가능한(nonlinearly separable) 클래스 경계가, 다중 뷰 특징 공간에서는 선형적으로 분리 가능(linearly separable)하게 변환되는 것을 특징으로 하는 방법.

**종속항 3** (분광법 범위)
독립항 1에 있어서,
상기 분광 스펙트럼은 SERS 스펙트럼, 라만 스펙트럼, 적외선 흡수 스펙트럼, 또는 형광 스펙트럼 중 하나이며,
상기 방법은 분광법의 종류에 무관하게 적용 가능한 것을 특징으로 하는 방법.

**종속항 4** (피크 비율 뷰)
독립항 1에 있어서,
상기 다중 뷰 특징 벡터에, 사전 정의된 복수의 피크 쌍에 대해 강도 비율(intensity ratio) R_ab = I(peak_a) / I(peak_b)를 산출한 비율 벡터를 추가 뷰로 연결하는 단계를 더 포함하되,
상기 강도 비율은 기판 증강 인자(enhancement factor)가 상쇄되어 기판 간 변동에 강건한(robust) 특징을 제공하는 것을 특징으로 하는 방법.

**종속항 5** (차원 및 정보 보존)
독립항 1에 있어서,
상기 다중 뷰 특징 벡터의 차원은 3L이며 (L은 원시 스펙트럼의 파수 지점 수),
상기 1차 및 2차 도함수 연산은 가역적(reversible) 수치 연산으로서 원시 스펙트럼 정보의 손실 없이 표현 공간을 확장하는 것을 특징으로 하는 방법.

## IP-7: Peak-based 대사체 해석 하이브리드

### 독립항 1 (방법 청구항)

AI 분류 모델의 질환 판별 결과에 대해 분자 수준의 근거를 제공하는 해석 방법으로서,

(a) 복수의 질환군 및 비질환군 피검자의 분광 스펙트럼에서, 질환군과 비질환군 간 또는 상이한 질환 아형 간에 통계적으로 유의미한 강도 차이를 갖는 감별 파수 영역(discriminative spectral band)을 식별하는 단계;

(b) 복수의 표준물질(N종, N ≥ 50)에 대해 동일한 분석 조건에서 실측한 참조 스펙트럼으로 구성된 참조 라이브러리를 제공하는 단계;

(c) 상기 감별 파수 영역의 중심 파수와 상기 참조 라이브러리의 각 표준물질의 피크 위치를 비교하여, 파수 차이가 사전 정의된 허용 오차(tolerance, ±δ cm⁻¹) 이내인 표준물질을 후보 대사체로 매핑하는 단계;

(d) 각 후보 대사체에 대해, 해당 대사체의 참조 스펙트럼과 피검자 스펙트럼 간의 유사도 점수(similarity score)를 산출하는 단계;

(e) AI 분류 모델의 특징 중요도(feature importance)로부터 각 감별 파수 영역이 분류 결정에 기여한 기여도 점수(contribution score)를 산출하는 단계;

(f) 상기 유사도 점수와 기여도 점수를 결합하여, 각 후보 대사체의 종합 점수를 산출하고, 질환 판별에 기여한 주요 대사체를 순위화하는 단계;

(g) 상기 주요 대사체를 공개 대사체 데이터베이스(KEGG, HMDB 등)와 교차 참조하여, 관련 대사 경로(metabolic pathway)를 보고하는 단계;

를 포함하는 AI 분류 결과의 분자 해석 방법.

### 독립항 2 (참조 라이브러리 청구항)

분광 분석 기반 AI 진단 시스템에서 사용되는 대사체 참조 라이브러리의 구축 방법으로서,

(a) N종(N ≥ 50)의 순수 표준물질을 개별적으로 준비하는 단계;

(b) 상기 각 표준물질에 대해, 질환 진단에 사용되는 분광 분석 시스템과 동일한 측정 조건(동일 기판, 동일 분광기, 동일 레이저 파장, 동일 노출 시간)에서 스펙트럼을 측정하는 단계;

(c) 각 표준물질의 스펙트럼에서 피크를 검출하고, 각 피크의 파수 위치, 상대 강도, 및 진동 모드(vibration mode) 정보를 기록하여 피크 목록을 생성하는 단계;

(d) 상기 피크 목록을 구조화된 데이터베이스로 저장하는 단계;

를 포함하되,

상기 참조 라이브러리의 모든 스펙트럼이 진단 시스템과 동일한 분석 조건에서 측정됨으로써, 문헌 기반 참조값 대비 기판 효과, 장비 응답 함수, 및 용매 환경 차이에 의한 피크 이동 오차가 최소화되는 것을 특징으로 하는 참조 라이브러리 구축 방법.

### 종속항 그룹

**종속항 1** (감별 피크 식별 방법)
독립항 1에 있어서,
상기 (a) 단계의 감별 파수 영역 식별은:
(a-1) 스펙트럼에 Savitzky-Golay 평활화(window ≥ 7, polynomial order ≥ 2)를 적용하는 단계;
(a-2) 동적 prominence 임계값(= 계수 × (최대값 - 최소값), 계수 ≤ 0.05)으로 피크를 검출하는 단계;
(a-3) 각 피크 위치에서 질환군과 비질환군 간의 통계 검정(Mann-Whitney U 검정 또는 t-검정)을 수행하고, 다중비교 보정(Bonferroni 또는 Benjamini-Hochberg)을 적용하여 유의미한 피크를 선별하는 단계;
를 포함하는 것을 특징으로 하는 방법.

**종속항 2** (매칭 알고리즘)
독립항 1에 있어서,
상기 (c) 단계의 매핑은, 허용 오차 δ = 10 cm⁻¹ 내지 15 cm⁻¹이며,
하나의 감별 파수 영역에 복수의 후보 대사체가 매핑되는 경우, 상기 (d) 단계의 유사도 점수에 의해 순위화하여 최고 유사도 대사체를 우선 후보로 선택하는 것을 특징으로 하는 방법.

**종속항 3** (유사도 점수)
독립항 1에 있어서,
상기 (d) 단계의 유사도 점수는, 후보 대사체의 참조 스펙트럼을 피검자 스펙트럼의 파수 그리드에 보간(interpolation)한 후, 중첩 영역(overlap ≥ 100 cm⁻¹)에서의 정규화된 피어슨 상관계수로 산출되는 것을 특징으로 하는 방법.

**종속항 4** (기여도 점수)
독립항 1에 있어서,
상기 (e) 단계의 기여도 점수는, 분류 모델이 선형 모델(로지스틱 회귀)인 경우, 해당 감별 파수 영역에 속하는 파수 지점들의 계수 절대값 합을 전체 계수 절대값 합으로 나눈 상대 기여도로 정의되며,
상기 계수의 부호(sign)는 해당 영역의 강도가 질환군에서 증가하는지(양) 감소하는지(음)를 나타내는 것을 특징으로 하는 방법.

**종속항 5** (종합 점수)
독립항 1에 있어서,
상기 (f) 단계의 종합 점수는 다음과 같이 산출되는 것을 특징으로 하는 방법:
특정 질환 아형에 대해, 후보 대사체 m이 매핑된 감별 파수 영역의 수(n_peaks)와 해당 대사체의 평균 유사도 점수(mean_sim)의 곱:
composite_score(m) = n_peaks(m) × mean_sim(m)

**종속항 6** (피크 강도 비율 바이오마커)
독립항 1에 있어서,
상기 (a) 단계에서 식별된 감별 파수 영역 중 생물학적으로 관련된 피크 쌍에 대해, 피크 강도 비율 R = I(peak_A) / I(peak_B)를 산출하는 단계를 더 포함하되,
상기 분모 피크는 내인성 기준물질(예: 크레아티닌, ~683 cm⁻¹)의 피크를 사용함으로써, 시료 농도 변동을 보정하고 기판 증강 인자를 상쇄하여 기판-독립적(substrate-independent) 바이오마커를 구성하는 것을 특징으로 하는 방법.

**종속항 7** (Voigt 피크 피팅)
독립항 1에 있어서,
상기 감별 파수 영역의 정량적 분석을 위해, 각 피크를 Voigt 프로파일(가우시안과 로렌츠 함수의 합성곱)로 피팅하여 피크 면적, 피크 높이, 반치전폭(FWHM), 및 피크 위치 이동량을 추출하되,
상기 FWHM은 Thompson 근사식: f_V ≈ 0.5346 × f_L + √(0.2166 × f_L² + f_G²) (f_L = 2γ, f_G = 2σ√(2ln2))에 의해 산출되는 것을 특징으로 하는 방법.

**종속항 8** (암종별 대사 시그니처)
독립항 1에 있어서,
상기 (f) 단계의 순위화를 각 질환 아형별로 독립적으로 수행하여, 아형 특이적(type-specific) 대사체 시그니처를 생성하고,
특정 아형에서만 높은 종합 점수를 보이는 고유(unique) 대사체와, 복수의 아형에서 공통으로 나타나는 공유(shared) 대사체를 구분하여 보고하는 것을 특징으로 하는 방법.

**종속항 9** (사후 해석)
독립항 1에 있어서,
상기 방법은 분류 모델의 재학습 없이, 이미 학습된 모델의 추론 결과에 대한 사후(post-hoc) 해석으로 적용되며,
상기 해석 결과는 분류 모델의 예측 정확도에 영향을 미치지 않는 것을 특징으로 하는 방법.

**종속항 10** (17개 사전정의 밴드)
독립항 1에 있어서,
상기 감별 파수 영역은 SERS 소변 스펙트럼에서 사전 정의된 17개의 생화학적 밴드에 기초하여 식별되며,
상기 17개 밴드는 ~448 cm⁻¹(고리 변형), ~539 cm⁻¹(S-S 신축), ~618 cm⁻¹(C-S 신축), ~683 cm⁻¹(크레아티닌), ~724 cm⁻¹(아데닌), ~795 cm⁻¹(히푸르산), ~849 cm⁻¹(티로신), ~895 cm⁻¹(요산), ~934 cm⁻¹(C-C 단백질), ~999 cm⁻¹(페닐알라닌), ~1148 cm⁻¹(C-N), ~1231 cm⁻¹(아미드III), ~1293 cm⁻¹(CH₂), ~1352 cm⁻¹(트립토판), ~1449 cm⁻¹(CH₂ 변형), ~1597 cm⁻¹(퓨린 C=C), ~1651 cm⁻¹(아미드I)을 포함하는 것을 특징으로 하는 방법.
