# 가출원 초안 — 특허 #11

# 소변 SERS 스펙트럼의 피크 기반 대사체 해석 방법 및 시스템

**Method and System for Peak-Based Metabolite Interpretation of Urine SERS Spectra**

---

## 1. 기술 분야

본 발명은 표면증강라만분광(SERS) 기반 다중 질환 스크리닝 시스템에서, 전체 스펙트럼 기계학습 분류 결과에 대해 피크 기반 대사체 해석을 결합하여 임상적 해석가능성을 제공하는 방법 및 시스템에 관한 것이다. 보다 구체적으로는 (i) 전체 스펙트럼을 입력으로 하는 기계학습 분류기의 판별 성능을 유지하면서, (ii) 사전 구축된 대사체 참조 라이브러리와의 교차 검증을 통해 분류 결과의 생물학적 근거를 자동으로 제시하는 하이브리드 진단 방법에 관한 것이다.

---

## 2. 배경 기술

### 2.1 종래 기술의 문제점

SERS 기반 질환 스크리닝 시스템의 분류 방법은 크게 두 가지로 나뉘며, 각각 다음과 같은 한계를 갖는다:

1. **전체 스펙트럼 기계학습 접근법 (Full Spectrum ML)**
   - 스펙트럼의 모든 강도값을 입력 특징으로 사용하여 분류 성능이 우수하다.
   - 최근 문헌에서 AUC > 0.95를 달성하는 대다수 연구가 이 방식을 채택하고 있다.
   - 그러나 분류 근거가 불투명한 "블랙 박스(black box)" 문제를 가지며, 임상 현장에서의 수용성이 저하된다.
   - 규제기관(FDA, MFDS)의 AI 의료기기 심사에서 해석가능성(explainability)에 대한 요구가 증가하고 있다.

2. **피크 기반 접근법 (Peak-Based Features)**
   - 특정 파수 위치의 피크 강도, 면적, 비율 등을 특징으로 사용한다.
   - 각 피크를 특정 대사체에 할당(assignment)할 수 있어 생물학적 해석이 용이하다.
   - 그러나 피크만으로는 분류 성능이 전체 스펙트럼 대비 유의하게 낮으며, 이는 문헌에서 반복적으로 보고된 합의 사항이다.
   - 피크 검출 자체가 기판, pH, 농도에 따른 ±5~15 cm⁻¹ 변동으로 표준화가 어렵다.

3. **기존 SHAP/Grad-CAM 해석의 한계**
   - 기계학습 모델의 사후 해석(post-hoc explanation)으로 주요 파수 대역을 식별할 수 있으나, 이를 구체적 대사체와 매핑하려면 별도의 참조 데이터가 필요하다.
   - 문헌 기반 피크 할당은 기판 및 측정 조건에 따라 편차가 크며, 동일 측정 조건에서 실측된 참조 표준이 없으면 신뢰성이 제한된다.

### 2.2 해결하고자 하는 과제

본 발명은 다음을 달성하고자 한다:
- 전체 스펙트럼 기계학습의 분류 성능을 유지하면서, 분류 결과에 대한 대사체 수준의 해석을 자동으로 제공
- 동일 측정 조건에서 실측된 대사체 참조 라이브러리를 활용한 높은 신뢰도의 피크-대사체 매핑
- 암종별 차별적 대사체 패턴을 분류기 계수와 참조 라이브러리의 교차 참조로 자동 식별
- 기판 독립적 바이오마커 정량을 위한 피크 비율(peak ratio) 특징 생성

## 3. 발명의 상세한 설명

### 3.1 시스템 개요

본 발명의 시스템은 3개의 모듈로 구성되며, 기존 계층적 다질환 스크리닝 시스템(P-01)의 분류 모듈(모듈 D)에 해석 모듈(모듈 E)을 추가하는 구조이다:

```
[모듈 D] 계층적 분류 → [모듈 E-1] 계수-피크 교차분석
                     → [모듈 E-2] 참조 라이브러리 매칭
                     → [모듈 E-3] 피크 비율 특징 생성
                     → [출력] 분류 결과 + 대사체 해석 보고
```

**모듈 E-1: 계수-피크 교차분석부 (핵심)**

분류기(예: 로지스틱 회귀)의 학습된 계수 벡터와 사전 정의된 피크 위치 테이블을 교차 참조하여, 각 암종의 분류에 기여하는 주요 파수 대역과 대사체를 자동 식별한다.

```
Algorithm: CoefficientPeakCrossReference

입력:
  W = [w₁, w₂, ..., wₙ]  — 분류기 계수 벡터 (n = 특징 차원, 예: 935)
  G = [ν₁, ν₂, ..., νₙ]  — 각 특징에 대응하는 파수 그리드 (cm⁻¹)
  B = {band₁, ..., bandₘ}  — 사전 정의된 m개 피크 대역 (각각 파수 범위 + 대사체 목록)

출력:
  R = [(bandⱼ, metabolites, contribution_score)]  — 기여도 순 정렬된 피크-대사체 목록

처리:
  1. FOR EACH bandⱼ ∈ B:
       (a) bandⱼ의 파수 범위 [lo, hi] 내에 해당하는 계수 인덱스 집합 I 결정
       (b) contribution_score = Σ_{i∈I} |W[i]| / Σ_{all} |W|  — 해당 대역의 상대 기여도
       (c) sign = sign(mean(W[i∈I]))  — 양/음 기여 방향
  2. R을 contribution_score 내림차순 정렬
  3. 각 bandⱼ에 대해, 대응하는 대사체 목록과 기여 방향(↑/↓) 기록
  4. RETURN R
```

**모듈 E-2: 참조 라이브러리 매칭부**

자체 구축한 대사체 참조 라이브러리(별도 측정한 복수 대사체 표준품의 SERS 스펙트럼)와 환자 스펙트럼의 피크 위치를 비교하여, 피크-대사체 할당의 신뢰도를 검증한다.

```
Algorithm: ReferenceLibraryMatching

입력:
  S_patient = 환자 스펙트럼의 피크 위치 목록 [{pos, height, prominence}, ...]
  L_ref = 참조 라이브러리: {대사체명 → [실측 피크 위치 목록]}
  τ = 허용 편차 (tolerance, cm⁻¹)

출력:
  M = [(patient_peak, matched_metabolite, Δcm⁻¹, confidence)]

처리:
  1. FOR EACH patient_peak ∈ S_patient:
       FOR EACH metabolite ∈ L_ref:
         FOR EACH ref_peak ∈ L_ref[metabolite]:
           IF |patient_peak.pos − ref_peak| ≤ τ:
             Δ = |patient_peak.pos − ref_peak|
             confidence = 1 − Δ/τ  — 편차가 작을수록 높은 신뢰도
             M에 (patient_peak, metabolite, Δ, confidence) 추가
  2. 동일 patient_peak에 복수 대사체가 매칭되면 confidence 순 정렬
  3. RETURN M
```

**모듈 E-3: 피크 비율 특징 생성부**

두 피크의 강도 비율을 계산하여 기판 및 측정 조건에 독립적인 바이오마커 특징을 생성한다.

```
Algorithm: PeakRatioFeatureGeneration

입력:
  S = 전처리된 스펙트럼 강도 벡터
  G = 파수 그리드
  ratio_defs = [(name, numerator_range, denominator_range), ...]
    예: ("Phe/Creatinine", (990,1015), (675,695))

출력:
  F = {ratio_name: ratio_value}

처리:
  1. FOR EACH (name, num_range, denom_range) ∈ ratio_defs:
       (a) num_intensity = max(S[G ∈ num_range])   — 분자 피크 강도
       (b) denom_intensity = max(S[G ∈ denom_range]) — 분모 피크 강도
       (c) IF denom_intensity > ε:   — 0 division 방지
             F[name] = num_intensity / denom_intensity
           ELSE:
             F[name] = NaN
  2. RETURN F
```

### 3.2 대사체 참조 라이브러리 (핵심 자산)

본 발명의 핵심 구성 요소인 대사체 참조 라이브러리는 다음과 같이 구축된다:

- **구축 방법**: 복수(예: 73종)의 대사체 표준품을 동일 SERS 측정 조건(동일 기판, 동일 장비, 동일 프로토콜)에서 개별 측정
- **기록 항목**: 대사체명, 분자식, 주요 피크 위치(cm⁻¹), 피크 강도, 진동 모드 할당
- **매핑 테이블 구조**:

| 피크 대역 (cm⁻¹) | 파수 범위 | 매핑된 대사체 | 진동 모드 |
|:---|:---|:---|:---|
| ~618 | 610–630 | Cysteine, Adenine, Phenylalanine, Hippuric acid 등 | C-S stretch |
| ~683 | 675–695 | Creatinine, Guanine, Hippuric acid, Tyrosine 등 | Ring breathing |
| ~724 | 715–735 | Adenine, Hypoxanthine, Hippuric acid, Benzoic acid | Ring breathing |
| ~795 | 785–805 | Hippuric acid, Kynurenine, Uric acid | Ring/C-H |
| ~849 | 840–860 | Tyrosine, Tryptophan, Creatinine, Cysteine | Ring breathing |
| ~999 | 990–1015 | Phenylalanine, Hippuric acid, Benzoic acid | Ring breathing |
| ~1148 | 1138–1158 | Glycogen, Glucose, Xylose, Cysteine | C-N/C-O-C stretch |
| ~1231 | 1220–1245 | Tryptophan, Taurine, Kynurenine | Amide III |
| ~1352 | 1340–1365 | Adenine, Guanine, Tryptophan | CH deformation |
| ~1449 | 1435–1465 | Lipids, Fatty acids (비특이적) | CH₂ deformation |
| ~1597 | 1585–1610 | Adenine, Kynurenine, Tyrosine, Phenylalanine | C=C/Purine ring |
| ~1651 | 1640–1665 | Maleic acid, Kynurenine, Stearic acid | Amide I |
| ~1680 | 1670–1695 | Guanine, Uracil, NADH | C=O stretch |

*(전체 17개 피크 대역, 73종 대사체 표준품 기반)*

#### 참조 라이브러리의 기술적 우위

- **동일 조건 실측**: 문헌 기반 피크 할당(±5~15 cm⁻¹ 편차)과 달리, 환자 스펙트럼과 동일한 기판·장비·프로토콜에서 측정되어 매칭 신뢰도가 높다
- **정량적 기준선**: 표준품 순수 스펙트럼이 존재하여, 혼합물인 소변 스펙트럼에서 특정 대사체의 기여도를 추정할 수 있다
- **확장성**: 새로운 대사체 표준품을 추가 측정하여 라이브러리를 지속적으로 확장 가능

### 3.3 피크 비율 기반 기판 독립적 바이오마커 정량 (핵심 발명)

두 피크의 강도 비율(intensity ratio)은 다음과 같은 자기정규화(self-normalizing) 특성을 가진다:

```
Ratio = I(peak_A) / I(peak_B)
```

- 기판의 증강 효율(Enhancement Factor)이 전체 스펙트럼에 균일하게 적용되는 경우, 비율값은 기판 간 차이를 상쇄한다
- 레이저 파워 변동, 초점 미세 차이에 의한 전체 강도 변화가 비율에서 소거된다
- 서로 다른 SERS 기판(예: 금 나노입자 vs 은 나노막대)에서 측정된 스펙트럼 간에도 비교 가능한 바이오마커 특징이 된다

#### 실시예 — 주요 피크 비율 정의

| 피크 비율 명칭 | 분자 피크 (cm⁻¹) | 분모 피크 (cm⁻¹) | 생물학적 의미 |
|:---|:---|:---|:---|
| Phe/Creatinine | ~999 (Phenylalanine) | ~683 (Creatinine) | 아미노산/크레아티닌 비율 |
| Trp/Creatinine | ~849 (Tryptophan) | ~683 (Creatinine) | 트립토판 대사 변동 |
| UA/Creatinine | ~795 (Uric acid) | ~683 (Creatinine) | 요산/크레아티닌 비율 |
| Purine/Lipid | ~724 (Adenine) | ~1449 (CH₂) | 핵산 대사 vs 지질 |
| Amide/Ring | ~1651 (Amide I) | ~999 (Phe ring) | 단백질/아미노산 비율 |

- 크레아티닌(~683 cm⁻¹)을 분모로 사용하는 비율: 소변 농도 보정 효과 (임상 화학의 크레아티닌 보정과 동일 원리)
- 비율값의 암종별 분포 차이를 통계적으로 검증하여, 암종 특이적 대사체 비율 바이오마커로 활용

### 3.4 하이브리드 진단 방법의 통합 흐름

```
[1] 전체 스펙트럼 기계학습 분류
    └→ Stage 1: 질환 유무 판별 (P-01)
    └→ Stage 2: 질환 아형 식별 (P-01)
    └→ 생물학적 제약 보정 (P-02)
    └→ 분류 결과: 암종 X, 확률 p

[2] 피크 기반 대사체 해석 (본 발명)
    └→ E-1: 분류기 계수에서 주요 기여 파수 대역 추출
    └→ E-2: 참조 라이브러리와 매칭 → 대사체 식별
    └→ E-3: 피크 비율 계산 → 기판 독립적 바이오마커 값

[3] 통합 출력
    └→ 분류 결과 (암종, 확률) + 해석 보고 (기여 대사체, 변동 방향, 피크 비율)
    └→ 임상 리포트 (P-10) 내 "판정 근거" 섹션에 표시
```

핵심 효과: **분류 성능은 전체 스펙트럼 ML로 확보하고, 해석가능성은 피크 기반 대사체 분석으로 제공**하여, 성능과 해석가능성을 동시에 달성한다.

## 4. 청구항 (Claims)

### 독립항 1 (방법 청구항)

대사체 프로파일 데이터에 기반한 질환 분류 결과에 대해 피크 기반 대사체 해석을 제공하는 방법으로서,
(a) 생체 시료로부터 획득된 분광 스펙트럼의 전체 강도값을 입력으로 하여, 기계학습 분류기에 의해 질환 분류 결과를 획득하는 단계;
(b) 상기 기계학습 분류기의 학습된 계수 또는 특징 기여도(feature importance)로부터, 분류에 기여하는 파수 대역을 추출하는 단계;
(c) 사전 구축된 대사체 참조 라이브러리를 참조하여, 상기 추출된 파수 대역에 대응하는 대사체를 식별하는 단계;
(d) 상기 질환 분류 결과와 상기 식별된 대사체 정보를 결합하여, 분류 근거를 포함하는 해석 보고를 생성하는 단계;
를 포함하며,
상기 대사체 참조 라이브러리는 복수의 대사체 표준품을 상기 생체 시료와 동일한 측정 조건에서 개별 측정하여 구축된 것을 특징으로 하는, 피크 기반 대사체 해석 방법.

### 독립항 2 (시스템 청구항)

생체 시료의 분광 스펙트럼으로부터 질환을 분류하고 그 근거를 해석하는 시스템으로서,
상기 분광 스펙트럼의 전체 강도값을 입력으로 하여 질환 분류를 수행하는 기계학습 분류부;
복수의 대사체 표준품의 개별 측정 스펙트럼으로 구성된 대사체 참조 라이브러리 저장부;
상기 기계학습 분류부의 계수 또는 특징 기여도와 상기 대사체 참조 라이브러리를 교차 참조하여, 분류에 기여하는 대사체를 식별하는 교차분석부;
상기 질환 분류 결과와 상기 식별된 대사체 정보를 결합하여 해석 보고를 생성하는 보고 생성부;
를 포함하는, 피크 기반 대사체 해석 시스템.

### 독립항 3 (피크 비율 청구항)

분광 스펙트럼에서 기판 독립적 바이오마커 특징을 생성하는 방법으로서,
(a) 생체 시료의 분광 스펙트럼에서, 사전 정의된 제1 대사체에 대응하는 제1 파수 대역의 피크 강도를 측정하는 단계;
(b) 동일 스펙트럼에서, 사전 정의된 제2 대사체에 대응하는 제2 파수 대역의 피크 강도를 측정하는 단계;
(c) 상기 제1 피크 강도와 상기 제2 피크 강도의 비율을 계산하여 피크 비율 특징을 생성하는 단계;
를 포함하며,
상기 피크 비율 특징은 기판의 증강 효율 및 측정 조건의 전역적 변동이 분자와 분모에서 상쇄되어, 기판 및 측정 조건에 독립적인 바이오마커 값을 제공하는 것을 특징으로 하는 방법.

### 종속항

4. 청구항 1에 있어서, 상기 기계학습 분류기는 로지스틱 회귀 모델이며, 상기 (b) 단계의 계수 추출은 상기 로지스틱 회귀 모델의 가중치 벡터에서 각 파수 대역의 절대값 합을 산출하는 것을 특징으로 하는 방법.

5. 청구항 1에 있어서, 상기 대사체 참조 라이브러리는 50종 이상의 대사체 표준품의 SERS 스펙트럼으로 구성된 것을 특징으로 하는 방법.

6. 청구항 1에 있어서, 상기 (c) 단계에서 피크 위치의 매칭 허용 편차(tolerance)는 ±5~15 cm⁻¹인 것을 특징으로 하는 방법.

7. 청구항 1에 있어서, 상기 (d) 단계의 해석 보고는 암종별로 기여도가 높은 상위 N개(N ≥ 3)의 대사체 및 그 변동 방향(증가/감소)을 포함하는 것을 특징으로 하는 방법.

8. 청구항 3에 있어서, 상기 제2 대사체는 크레아티닌이며, 상기 제2 파수 대역은 675~695 cm⁻¹ 범위인 것을 특징으로 하는 방법.

9. 청구항 3에 있어서, 상기 제1 대사체는 페닐알라닌, 트립토판, 요산 중 적어도 하나이며, 상기 피크 비율은 소변 시료의 농도 보정 효과를 함께 제공하는 것을 특징으로 하는 방법.

10. 청구항 1에 있어서, 상기 분광 스펙트럼은 표면증강라만분광(SERS), 일반 라만분광, 적외분광(IR) 중 적어도 하나의 측정법으로부터 획득되는 것을 특징으로 하는 방법.

11. 청구항 1에 있어서, 상기 질환 분류는 계층적 2단계 분류(Stage 1: 질환 유무 판별, Stage 2: 질환 아형 식별)에 의해 수행되며, 상기 해석 보고는 Stage 2에서 식별된 질환 아형에 대한 대사체 근거를 제공하는 것을 특징으로 하는 방법.

12. 청구항 1에 있어서, 상기 (b) 단계와 (c) 단계를 복수의 질환 아형 각각에 대해 수행하여, 암종별 차별적 대사체 패턴을 식별하는 것을 특징으로 하는 방법.
