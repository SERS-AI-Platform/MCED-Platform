# 가출원 초안 — 특허 #2

# 생물학적 불가능성에 기반한 다중 분류기 출력 보정 방법 및 시스템

**Method and System for Correcting Multi-Classifier Output Based on Biological Impossibility**

---

## 1. 기술 분야

본 발명은 다중 질환 분류기의 출력 확률 벡터를 피검자의 생물학적 속성에 기반하여 보정하는 방법에 관한 것으로, 보다 구체적으로는 생물학적으로 불가능한 질환 클래스의 확률을 구조적으로 제거(마스킹)하고 잔여 확률을 재정규화하여 분류 정확도를 향상시키는 방법에 관한 것이다.

---

## 2. 배경 기술

### 2.1 종래 기술의 문제점

다중 질환(multi-disease) AI 분류 시스템에서 피검자의 인구통계학적 정보(성별, 연령 등)를 활용하는 종래의 방법은 다음과 같다:

1. **입력 특징 융합(feature fusion)**: 성별, 연령 등을 분류기의 입력 특징 벡터에 연접(concatenate)하여 학습한다. 이 방법은 인구통계 변수를 통계적 상관관계로만 학습하므로, 생물학적 불가능성(예: 남성의 난소암)을 완전히 배제하지 못한다. 분류기는 낮은 확률을 출력할 수 있으나, 0이 되지는 않는다.

2. **성별 분리 모델**: 남성용/여성용 모델을 별도 학습한다. 이 방법은 모델 관리 복잡도를 2배로 증가시키고, 성별 중립 질환(폐암, 대장암 등)에 대한 학습 데이터가 분할되어 성능이 저하된다.

3. **사후 처리 미적용**: 대다수의 AI 진단 시스템은 분류기 출력을 그대로 사용하며, 생물학적 제약을 반영하지 않는다.

### 2.2 구체적 문제 — PRO↔OVA 혼동

전립선암(PRO)은 100% 남성, 난소암(OVA)은 100% 여성에서만 발생한다. 그러나 두 암종의 대사체 프로파일이 유사한 경우, 다중 분류기는 여성 환자에게 전립선암 확률을 부여하거나 남성 환자에게 난소암 확률을 부여할 수 있다. 이는:
- 임상적으로 무의미한 위양성을 생성하고
- 정답 클래스의 상대적 확률을 희석하여
- 전체 분류 정확도를 저하시킨다.

### 2.3 해결하고자 하는 과제

본 발명은 다중 분류기의 사후(post-hoc) 확률 보정 방법으로서:
- 생물학적으로 불가능한 질환의 확률을 구조적으로 0으로 제거
- 잔여 확률을 재정규화하여 정답 클래스의 확률 증가
- 분류기 재학습 없이 적용 가능 (추론 시에만 적용)
- 성별 이외의 다양한 생물학적 제약으로 일반화 가능

## 3. 발명의 상세한 설명

### 3.1 개요

본 발명은 다중 질환 분류기의 출력 확률 벡터에 대해, 피검자의 생물학적 속성 정보를 이용하여 **생물학적 제약 마스크(biological constraint mask)**를 생성하고, 이를 확률 벡터에 적용한 후 재정규화하는 방법이다.

핵심 구별점: 본 발명은 통계적 상관(statistical correlation)이 아닌 **생물학적 불가능성(biological impossibility)**을 인코딩한다. 즉, "남성에서 난소암 확률이 낮다"가 아니라 "남성에서 난소암은 발생 불가능하므로 확률이 정확히 0이다"를 강제한다.

### 3.2 생물학적 제약 마스크 생성

#### 정의

생물학적 제약 테이블 C는 다음과 같은 매핑이다:

```
C: (생물학적 속성 값) → {허용 질환 클래스 집합}
```

#### 실시예 — 성별 제약

| 생물학적 속성 | 속성 값 | 마스킹 대상 질환 | 근거 |
|:---|:---|:---|:---|
| 성별 | 남성 (sex=1) | 난소암 (OVA) | 난소 부재 |
| 성별 | 여성 (sex=0) | 전립선암 (PRO) | 전립선 부재 |

#### 확장 가능한 생물학적 제약 예시

| 생물학적 속성 | 속성 값 | 마스킹 대상 질환 | 근거 |
|:---|:---|:---|:---|
| 자궁절제 이력 | 있음 | 자궁경부암, 자궁내막암 | 장기 부재 |
| 전립선절제 이력 | 있음 | 전립선암 | 장기 부재 |
| 연령 | < 30세 | 전립선암 | 역학적 불가 (발생률 0에 수렴) |
| 장기 이식 이력 | 특정 장기 절제 | 해당 장기 암 | 장기 부재 |

### 3.3 확률 보정 알고리즘 (핵심)

```
Algorithm: BiologicalConstraintCorrection

입력:
  P = [p₁, p₂, ..., pₖ]  — k개 질환 아형에 대한 분류기 출력 확률 벡터
  B = {b₁, b₂, ..., bₘ}  — 피검자의 생물학적 속성 집합
  C = 생물학적 제약 테이블

출력:
  P' = [p'₁, p'₂, ..., p'ₖ]  — 보정된 확률 벡터

처리:
  1. 마스크 벡터 M = [1, 1, ..., 1] ∈ {0,1}ᵏ 초기화
  2. FOR EACH 속성 bⱼ ∈ B:
       FOR EACH 질환 클래스 i ∈ {1,...,k}:
         IF C(bⱼ) 에서 클래스 i가 불가능:
           M[i] ← 0
  3. 원소별 곱: P_masked = P ⊙ M   — 불가능 클래스 확률 = 0
  4. 재정규화:
       S = Σᵢ P_masked[i]
       IF S > 0:
         P' = P_masked / S   — 합이 1이 되도록 재정규화
       ELSE:
         P' = P_masked       — 모든 클래스가 마스킹된 예외 케이스
  5. RETURN P'
```

### 3.4 구현 상세 (의사 코드)

```python
def apply_biological_constraint(type_probs, class_names, constraint_table, patient_attributes):
    """
    type_probs: np.ndarray, shape (N, K) — N명 피검자, K개 질환 클래스
    class_names: list of str — 각 클래스의 질환명
    constraint_table: dict — {(속성명, 속성값): [마스킹 대상 질환명 리스트]}
    patient_attributes: dict of np.ndarray — {속성명: 속성값 배열}
    """
    constrained = type_probs.copy()

    for attr_name, attr_values in patient_attributes.items():
        for attr_val, masked_diseases in constraint_table.get(attr_name, {}).items():
            # 해당 속성값을 가진 피검자 인덱스
            target_rows = np.where(attr_values == attr_val)[0]
            # 마스킹 대상 질환의 클래스 인덱스
            masked_cols = [i for i, name in enumerate(class_names) if name in masked_diseases]

            for col in masked_cols:
                constrained[target_rows, col] = 0.0

    # 행별 재정규화
    row_sums = constrained.sum(axis=1, keepdims=True)
    row_sums[row_sums == 0] = 1.0  # 0-division 방지
    constrained = constrained / row_sums

    return constrained
```

### 3.5 실시예 — 성별 제약 적용

**제약 테이블:**
```
constraint_table = {
    "sex": {
        1.0: ["OVA"],   # 남성 → 난소암 마스킹
        0.0: ["PRO"],   # 여성 → 전립선암 마스킹
    }
}
```

**보정 전 (여성 피검자, 실제 암종: OVA):**
```
P = [PRO: 0.15, OVA: 0.35, LUN: 0.20, CRC: 0.15, PAN: 0.10, BLC: 0.05]
→ argmax = OVA (정답이지만 확신도 낮음)
```

**보정 후:**
```
1. 마스킹: PRO → 0.00
2. 재정규화: sum = 0.85
   P' = [PRO: 0.00, OVA: 0.412, LUN: 0.235, CRC: 0.176, PAN: 0.118, BLC: 0.059]
→ argmax = OVA (확신도 35% → 41.2% 향상)
```

### 3.6 교란변수와의 구별

본 발명의 생물학적 제약 보정이 단순 인구통계 특징 융합과 근본적으로 다른 점:

| 특성 | 특징 융합 (종래) | 생물학적 제약 보정 (본 발명) |
|:---|:---|:---|
| 적용 시점 | 학습 시 (입력 단계) | 추론 시 (출력 단계) |
| 학습 영향 | 모델이 성별을 프록시로 학습할 위험 | 모델 학습에 영향 없음 |
| 보정 강도 | 확률적 (0에 근접하나 0은 아님) | 결정적 (정확히 0) |
| 생물학적 근거 | 통계적 상관 | 해부학적 불가능성 |
| 재학습 필요 | 필요 (특징 변경 시) | 불필요 (추론 파이프라인에 추가만) |
| 확장성 | 새 속성 추가 시 재학습 | 제약 테이블만 업데이트 |

## 4. 청구항 (Claims)

### 독립항 1 (방법 청구항)

대사체 프로파일 데이터에 기반한 다중 질환 분류기의 출력을 보정하는 방법으로서,
(a) 다중 질환 분류기로부터 피검자의 대사체 프로파일 데이터에 대한 복수의 질환 아형별 확률값을 포함하는 확률 벡터를 획득하는 단계;
(b) 상기 피검자의 생물학적 속성 정보를 획득하는 단계;
(c) 미리 정의된 생물학적 제약 테이블을 참조하여, 상기 피검자의 생물학적 속성에 의해 발생이 불가능한 질환 아형을 결정하는 단계;
(d) 상기 확률 벡터에서 상기 발생 불가능 질환 아형에 해당하는 확률값을 0으로 설정하는 단계;
(e) 상기 (d) 단계 후 잔여 확률값의 합이 1이 되도록 재정규화(renormalization)하는 단계;
를 포함하는, 생물학적 제약 기반 분류기 출력 보정 방법.

### 독립항 2 (시스템 청구항)

대사체 프로파일 데이터로부터 복수의 질환 아형별 확률값을 출력하는 다중 질환 분류기;
피검자의 생물학적 속성 정보를 저장하는 환자 정보 저장부;
생물학적 속성과 발생 불가능 질환 아형 간의 매핑을 정의하는 생물학적 제약 테이블;
상기 다중 질환 분류기의 출력 확률 벡터에서, 상기 생물학적 제약 테이블에 의해 결정된 발생 불가능 질환 아형의 확률을 0으로 마스킹하고 잔여 확률을 재정규화하는 보정부;
를 포함하는, 생물학적 제약 기반 다중 질환 분류 시스템.

### 종속항

3. 청구항 1에 있어서, 상기 생물학적 속성은 성별이며, 상기 발생 불가능 질환 아형은 남성 피검자에 대한 난소암 및 여성 피검자에 대한 전립선암인 것을 특징으로 하는 방법.

4. 청구항 1에 있어서, 상기 생물학적 속성은 장기 절제 이력이며, 상기 발생 불가능 질환 아형은 절제된 장기에서 기원하는 암종인 것을 특징으로 하는 방법.

5. 청구항 1에 있어서, 상기 생물학적 제약 테이블은 복수의 생물학적 속성에 대한 제약을 포함하며, 상기 (c) 및 (d) 단계는 복수의 생물학적 속성을 순차적으로 적용하여 마스크 벡터를 누적 생성하는 것을 특징으로 하는 방법.

6. 청구항 1에 있어서, 상기 다중 질환 분류기는 계층적 2단계 분류기의 제2 분류기(Stage 2)이며, 제1 분류기(Stage 1)에서 양성으로 판정된 시료에 대해서만 상기 보정이 적용되는 것을 특징으로 하는 방법.

7. 청구항 1에 있어서, 상기 보정은 분류기의 학습(training)과 독립적으로 추론(inference) 시에만 적용되는 것을 특징으로 하는 방법.

8. 청구항 1에 있어서, 상기 대사체 프로파일 데이터는 표면증강라만분광(SERS), 일반 라만분광, ELISA, 질량분석(MS), 핵자기공명(NMR) 중 적어도 하나의 측정법으로부터 획득되는 것을 특징으로 하는 방법.

9. 청구항 1에 있어서, 상기 생물학적 속성 정보가 결측(missing)인 경우, 질환 아형의 역학적 특성에 기반하여 속성값을 대입(imputation)하는 단계를 추가로 포함하며, 상기 대입은 해당 질환의 성별 특이성에 기반하는 것을 특징으로 하는 방법.

10. 청구항 1에 있어서, 상기 보정 전후의 확률 벡터 변화량을 산출하여 보정 기여도(correction impact)를 기록하는 단계를 추가로 포함하는 것을 특징으로 하는 방법.

### 5.3 교란변수 독립성 검증

본 발명의 보정이 성별 프록시 학습이 아님을 확인:
- 인구통계 변수(나이, 성별, BMI)만으로 학습 시 Stage 1 AUC ≈ 0.60~0.70 (기회 수준)
- 스펙트럼 특징과 성별 간 피어슨 상관: 대부분 |r| < 0.1
- 연령 매칭 부분집합에서도 보정 효과 동일하게 유지

**결론**: 본 발명의 분류기는 대사체 패턴을 학습하며, 생물학적 제약 보정은 대사체 패턴에 의한 우연적 혼동만을 제거한다.

## 7. 명세서 기재 확장

### 7.1 다질환 확장
성별 외에도 다음 제약 적용 가능성을 명세서에 기재:
- 자궁경부암/자궁내막암 ↔ 자궁절제 이력
- 소아 특이 암 ↔ 연령 (소아/성인 구분)
- 유방암 ↔ 남성 (극히 드문 발생이므로 확률 감소 적용, 완전 마스킹은 아님)

### 7.2 소프트 마스킹 변형
- 완전 마스킹 (hard mask): 확률 → 0 (생물학적 불가능)
- 부분 감소 (soft mask): 확률 × α (0 < α < 1) (매우 드문 경우)
- 이를 통해 남성 유방암처럼 극히 드물지만 불가능은 아닌 경우에도 적용 가능
