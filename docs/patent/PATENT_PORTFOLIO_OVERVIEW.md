## 5. 전체 포트폴리오 청구 범위 설계 원칙

### 5.1 독립항 범위 — "대사체 프로파일 데이터"

모든 독립항의 입력 데이터는 **"대사체 프로파일 데이터"**로 기재:
- 정의: "생체 시료에 포함된 복수의 대사체의 농도 또는 분광학적 강도값으로 구성된 다변량 수치 벡터"
- 포괄 범위: SERS, 일반 라만, ELISA, MS, NMR, 면역분석, 전기화학 센서 등
- SERS 한정은 종속항에서 기재

### 5.2 명세서 이중 기재 — 스크리닝 + Diagnostic

| 구분 | 청구항 | 명세서 |
|:---|:---|:---|
| 스크리닝 | ✅ 독립항에 명시 | ✅ 상세 기재 |
| Diagnostic | ❌ 초기 출원에서 미청구 | ✅ 상세 기재 (확장 대비) |

### 5.3 침해 탐지 용이성

| 특허 | 침해 탐지 방법 |
|:---|:---|
| P-01 (계층적 분류) | 경쟁사 제품의 2단계 판정 구조 확인 |
| P-02 (생물학적 제약) | 남성 피검자 결과에서 OVA 확률=0 여부 확인 |
| P-03 (QC) | 자동 재측정 지시 기능 존재 여부 |
| P-05 (다중 임계값) | 모드 전환 기능 존재 여부 |
| P-10 (리포트 UI) | 화면 캡처 비교 (디자인특허) |
| P-11 (피크 해석) | 진단 리포트에 대사체 근거 표시 + 참조 라이브러리 사용 여부 |
