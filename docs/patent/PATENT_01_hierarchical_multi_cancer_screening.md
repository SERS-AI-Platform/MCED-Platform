# 가출원 초안 — 특허 #1

# 대사체 프로파일 데이터에 기반한 계층적 다질환 스크리닝 방법 및 시스템

**Method and System for Hierarchical Multi-Disease Screening Based on Metabolite Profile Data**

---

## 1. 기술 분야

본 발명은 생체 시료로부터 획득한 대사체 프로파일 데이터를 이용하여 복수의 질환을 동시에 스크리닝하는 방법 및 시스템에 관한 것으로, 보다 구체적으로는 2단계 계층적 분류 구조를 통해 (i) 질환 유무를 판별하고 (ii) 질환 아형을 식별하되, 만성질환 대조군을 포함한 현실적 임상 환경에서의 판별력을 확보하는 방법에 관한 것이다.

---

## 2. 배경 기술

### 2.1 종래 기술의 문제점

기존의 체외진단 AI 분류 시스템은 다음과 같은 한계를 갖는다:

1. **단일 단계(single-stage) 분류**: 정상 vs 질환 판별과 질환 아형 식별을 단일 분류기로 수행하여, 암종 수 증가 시 정확도가 급격히 하락한다.
   - 선행기술 US20210215610A1 (Virginia Tech): PCA/DAPC 단일 분류, 질환별 개별 모델
   - 선행기술 CN115078331B (우한대): SVM 단일 분류

2. **건강군만 대조군으로 사용**: 실제 임상 환경에서 피검자는 당뇨, 고혈압 등 만성질환을 동반하는 경우가 대다수이나, 기존 시스템은 건강한 정상군만을 대조군으로 사용하여 위양성률이 높다.

3. **단일 측정법 한정**: 기존 특허들은 특정 측정법(일반 라만, 특정 SERS 기판 등)에 한정되어 있어 범용성이 떨어진다.

### 2.2 해결하고자 하는 과제

본 발명은 다음을 달성하고자 한다:
- 5종 이상 암종의 동시 스크리닝과 아형 식별을 단일 시스템으로 수행
- 만성질환자를 포함한 현실적 대조군에서도 높은 판별력 유지
- 측정법에 비의존적인 범용 분류 프레임워크 제공

## 3. 발명의 상세한 설명

### 3.1 시스템 개요

본 발명의 시스템은 4개의 모듈로 구성된다:

```
[모듈 A] 데이터 획득 → [모듈 B] 품질 제어 → [모듈 C] 신호 전처리 → [모듈 D] 계층적 분류
```

**모듈 A: 데이터 획득부**
- 생체 시료(소변, 혈액, 타액, 눈물 등)로부터 대사체 프로파일 데이터를 획득
- 대사체 프로파일 데이터: 복수의 대사체 농도 또는 분광학적 강도값으로 구성된 다변량 수치 벡터
- 획득 수단: SERS(표면증강라만분광), 일반 라만분광, ELISA, 질량분석(MS), 핵자기공명(NMR), 면역분석 등 — 수치 벡터 형태의 출력이 생성되는 모든 측정법을 포함

**모듈 B: 품질 제어부** (별도 출원 #3에서 상세화)
- 획득된 데이터의 학습/추론 적합성 판정
- 부적합 데이터 자동 재측정 지시

**모듈 C: 신호 전처리부**
- 잡음 제거, 기저선 보정, 정규화를 순차 적용하여 특징 벡터 생성
- 특징 벡터 차원: n (측정법에 따라 가변, 예: SERS 935차원, MS 수천 차원)

**모듈 D: 계층적 분류부 (핵심)**

### 3.2 계층적 2단계 분류 구조 (핵심 발명)

#### Stage 1: 질환 유무 판별기 (Binary Classifier)

```
입력: 특징 벡터 x ∈ ℝⁿ
출력: P(질환) ∈ [0, 1]
판정: P(질환) > θ₁ → "양성" → Stage 2로 진행
      P(질환) ≤ θ₁ → "음성" → 종료
```

- 분류기: 로지스틱 회귀(LR), 서포트 벡터 머신(SVM), 랜덤 포레스트(RF), 심층 신경망 중 택일 또는 앙상블
- **대조군 구성**: 건강 정상군(NOR) + 복수의 만성질환군(당뇨 DIA, 고혈압 HBP, 혈액투석 H.D. 등)
- 임계값 θ₁: 사용 목적(스크리닝/진단 확인)에 따라 조정 가능 (아래 3.4절)

#### Stage 2: 질환 아형 식별기 (Multi-class Classifier)

```
입력: 동일 특징 벡터 x ∈ ℝⁿ (Stage 1과 동일 입력)
조건: Stage 1에서 양성 판정된 시료만 진입
출력: 확률 벡터 [P(Type₁), P(Type₂), ..., P(Typeₖ)]
판정: argmax → 가장 높은 확률의 질환 아형으로 분류
```

- k ≥ 5인 복수 질환 아형 동시 식별
- 실시예에서 k = 6~8: 전립선암(PRO), 난소암(OVA), 폐암(LUN), 대장암(CRC), 췌장암(PAN), 방광암(BLC) 등

#### 게이트 구조의 핵심 효과

Stage 1이 "게이트(gate)"로서 기능하여:
1. **비암 시료의 조기 배제**: 만성질환/정상 시료를 Stage 1에서 배제하여 Stage 2의 부담 경감
2. **클래스 불균형 완화**: Stage 2는 암 시료만으로 학습/추론하여 비암 클래스에 의한 편향 제거
3. **임상 워크플로우 정합**: 의사의 실제 판단 프로세스(암 의심 → 암종 감별)와 일치

### 3.3 만성질환 대조군 포함 (핵심 발명)

종래의 AI 진단 시스템이 건강군만을 대조군으로 사용한 것과 달리, 본 발명은 **비암 대조군에 만성질환군을 포함**한다:

| 대조군 카테고리 | 예시 | 목적 |
|:---|:---|:---|
| 건강 정상군 (NOR) | 질환 없는 건강인 | 기본 대조 |
| 당뇨군 (DIA) | 제2형 당뇨 환자 | 대사 이상 감별 |
| 고혈압군 (HBP) | 고혈압 환자 | 심혈관계 감별 |
| 혈액투석군 (H.D.) | 만성신부전 투석 환자 | 신장 대사 감별 |

**효과**: 실제 건강검진 모집단에서 만성질환 보유율이 60% 이상인 점을 반영하여, 건강군 대비가 아닌 만성질환 대비에서도 암을 정확히 감별할 수 있다.

### 3.4 다중 임계값 운영 모드

동일 분류 모델에 복수의 임계값 세트를 적용하여 사용 목적별 운영 모드를 제공한다:

| 모드 | Stage 1 임계값 | Stage 2 임계값 | 용도 |
|:---|:---|:---|:---|
| 스크리닝 모드 | θ₁_low (고민감도) | θ₂_low | 건강검진, 대규모 선별 |
| 균형 모드 | θ₁_mid (Youden's J) | θ₂_mid | 일반 진료 |
| 확인 모드 | θ₁_high (고특이도) | θ₂_high | 진단 보조, 암종 확정 |

- 임계값 최적화: ROC 곡선에서 Youden's J index, F1-optimal, 고특이도(95%+) 기준으로 자동 산출

### 3.5 학습 방법

#### 데이터 분할
- 피검자(subject) 단위 층화 분할: 동일 피검자의 복수 측정값이 학습/검증/평가 세트에 혼입되지 않도록 함
- StratifiedGroupKFold (k=5): 질환 아형별 비율을 유지하면서 피검자 단위 그룹화

#### 라벨 생성
- 이진 라벨: 암 = 1, 비암(NOR+DIA+HBP+H.D.) = 0
- 암종 라벨: 암 시료에 대해서만 0~(k-1) 인덱스 부여

#### 손실 함수
```
L = w₁·BCE(ŷ_binary, y_binary) + w₂·CE(ŷ_type, y_type)    [y_type은 암 시료만]
```
- w₁, w₂: 가중치 (기본값 1.0)
- Stage 2 CE: 클래스 불균형 대응으로 focal loss (γ=2.0) 또는 라벨 스무딩(ε=0.1) 적용 가능

## 4. 청구항 (Claims)

### 독립항 1 (방법 청구항)

생체 시료로부터 획득된 대사체 프로파일 데이터를 이용하여 복수의 질환을 스크리닝하는 방법으로서,
(a) 상기 대사체 프로파일 데이터를 전처리하여 특징 벡터를 생성하는 단계;
(b) 제1 분류기에 의해, 상기 특징 벡터로부터 질환 유무를 이진 판별하는 단계 (Stage 1);
(c) 상기 (b) 단계에서 양성으로 판정된 시료에 대해서만, 제2 분류기에 의해, 상기 특징 벡터로부터 복수(k ≥ 5)의 질환 아형 중 하나로 분류하는 단계 (Stage 2);
를 포함하며,
상기 (b) 단계의 이진 판별에서 비질환 대조군은 건강 정상군과 1종 이상의 만성질환군을 포함하는 것을 특징으로 하는, 계층적 다질환 스크리닝 방법.

### 독립항 2 (시스템 청구항)

생체 시료로부터 대사체 프로파일 데이터를 획득하는 데이터 획득부;
상기 대사체 프로파일 데이터로부터 특징 벡터를 생성하는 전처리부;
상기 특징 벡터를 입력으로 하여 질환 유무를 이진 판별하는 제1 분류기;
상기 제1 분류기에서 양성으로 판정된 시료에 대해, 상기 특징 벡터를 입력으로 하여 복수(k ≥ 5)의 질환 아형 중 하나로 분류하는 제2 분류기;
를 포함하며,
상기 제1 분류기의 비질환 대조군은 건강 정상군과 1종 이상의 만성질환군을 포함하도록 학습된 것을 특징으로 하는, 계층적 다질환 스크리닝 시스템.

### 종속항

3. 청구항 1에 있어서, 상기 대사체 프로파일 데이터는 표면증강라만분광(SERS), 일반 라만분광, ELISA, 질량분석(MS), 핵자기공명(NMR) 중 적어도 하나의 측정법으로부터 획득되는 것을 특징으로 하는 방법.

4. 청구항 1에 있어서, 상기 생체 시료는 소변, 혈액, 타액, 눈물, 땀 중 적어도 하나인 것을 특징으로 하는 방법.

5. 청구항 1에 있어서, 상기 만성질환군은 당뇨, 고혈압, 만성신부전 중 적어도 하나를 포함하는 것을 특징으로 하는 방법.

6. 청구항 1에 있어서, 상기 복수의 질환 아형은 전립선암, 난소암, 폐암, 대장암, 췌장암, 방광암 중 5종 이상을 포함하는 것을 특징으로 하는 방법.

7. 청구항 1에 있어서, 상기 (b) 단계는 복수의 임계값 세트를 저장하고, 사용 목적(스크리닝/균형/확인)에 따라 상이한 임계값 세트를 선택적으로 적용하는 것을 특징으로 하는 방법.

8. 청구항 1에 있어서, 상기 (b) 단계에서 사용되는 제1 분류기는 로지스틱 회귀 모델이며, 상기 (c) 단계에서 사용되는 제2 분류기는 로지스틱 회귀 모델과 1차원 잔차 신경망(ResNet-1D)의 가중 앙상블인 것을 특징으로 하는 방법.

9. 청구항 1에 있어서, 상기 특징 벡터를 생성하는 단계는:
   (a-1) 지문 영역(fingerprint region)으로 트리밍하는 단계;
   (a-2) 사비츠키-골레이 필터로 평활화하는 단계;
   (a-3) 롤링 최소값 기반 기저선 보정 단계;
   (a-4) 표준정규변량(SNV) 정규화 단계;
   (a-5) 고정 공통 파수 그리드로 보간하는 단계;
   를 포함하는 것을 특징으로 하는 방법.

10. 청구항 1에 있어서, 상기 학습 시 동일 피검자의 복수 측정값이 학습 세트와 평가 세트에 동시에 포함되지 않도록 피검자 단위 층화 그룹 교차검증(Stratified Group K-Fold)을 적용하는 것을 특징으로 하는 방법.

11. 청구항 1에 있어서, 상기 (c) 단계의 분류 결과에 대해, 피검자의 생물학적 속성에 기반하여 불가능한 질환 아형의 확률을 0으로 마스킹하고 나머지 확률을 재정규화하는 사후 보정 단계를 추가로 포함하는 것을 특징으로 하는 방법.

12. 청구항 1에 있어서, 상기 대사체 프로파일 데이터에 피검자의 임상 변수(나이, 성별, BMI 중 적어도 하나)를 연접(concatenation)하여 융합 특징 벡터를 생성하는 단계를 추가로 포함하는 것을 특징으로 하는 방법.

| 대조군 | 건강군만 | **만성질환 포함** (DIA, HBP, H.D.) |
| 동시 암종 수 | 개별 질환 모델 | **5~8종 동시** |
| 입력 데이터 | 일반 라만 | **대사체 프로파일** (측정법 무관) |
| 운영 모드 | 단일 역치 | **3-threshold 다중 모드** |

---

## 6. 도면 설명 (출원 시 포함)

- **도 1**: 전체 시스템 블록 다이어그램 (모듈 A→B→C→D)
- **도 2**: 2단계 계층적 분류 흐름도 (Stage 1 게이트 → Stage 2)
- **도 3**: 대조군 구성 비교 (종래 vs 본 발명)
- **도 4**: ROC 곡선 (Stage 1, 5-암종 + 만성질환 대조군)
- **도 5**: 혼동 행렬 (Stage 2, 8-암종)
- **도 6**: 3-threshold 운영 모드 개념도

## 7. 명세서 기재 확장 (diagnostic 대비)

명세서에는 스크리닝 용도 외에도 다음을 기재한다:
- "진단 보조(diagnostic aid)" 용도의 가능성
- 전향적(prospective) 임상시험 데이터에 의한 진단 성능 검증 계획
- 규제기관(FDA, MFDS) 승인 경로(Class II De Novo / Class III PMA)와의 연계

이는 추후 diagnostic 청구항 확장을 위한 명세서 충실화 목적이며, 초기 청구항은 스크리닝에 한정한다.
